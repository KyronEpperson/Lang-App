# nan-en digest (writers read this INSTEAD of docs/profiles/nan.md)

Course: English for Taiwanese (Taigi) speakers. Explanations in **written Taigi, MOE recommended Han characters** (owner, 2026-11-27). Scaffold = copy of the Cantonese course `yue-en`; every Cantonese string is a placeholder. Parity vs ko-en; `deviations.json` (lead's) covers all English-side changes. Orthography authority = `tools/i18n/nan/NOTES.md` (the live Taigi interface): the course must read like the interface.

## 1. Writing rules
1. **Write the Taigi word in its MOE character; never the Mandarin word, never the Cantonese one.** Mandarin never: 不 在 要(want) 給 個(classifier) 這裡 那裡 什麼 怎麼 很 了(aspect) 們 他 她 吃 喝 沒有 嗎 呢 吧 說 誰 東西. Allowed only in fixed Sino compounds: 不規則 不可數 不定詞 不定冠詞 個人 現在式 在地 重要 需要 主要 要緊 其他 說明 了解 了後. Cantonese never: 嘅 係 唔 冇 喺 咗 佢 哋 啲 嗰 嘢 咩 乜 噉 攞 搵 諗 睇 瞓 攰 畀 嚟 屋企 而家 尋日 聽日 鍾意 點解 邊度 邊個 幾時; Hong Kong words 的士 港幣 埋單 串字 大楷 眾數 第三身. Check: `node tools/content/nan/taigi_lint.js <files>` → PASS, then judge every Mandarin warning.
2. **Voice:** friendly tutor, **你** only (never 您); 咱 = "we, you and I" (「咱來看」); 恁 = you (plural); plain imperatives (「揀正確的答案」). Short sentences, common words: most readers read Mandarin faster than Taigi, so never use a rare character where a common Taigi word exists. 矣 for a change / done; 喔 / 啦 rarely, never in `why`.
3. **Characters:** Taiwan forms 裡 著 線 台 (change the scaffold's 裏 着 綫). No character outside the BMP except **𪜶 (in)** "they / their", always followed by (in), only where "they" must be glossed. No Tâi-lô elsewhere except in `pron` / `alphabet` sound comparisons, in half-width parentheses.
4. **Spacing / punctuation:** half-width space between Han and Latin letters or digits (`be 動詞`, `第 3 課`, `5 萬箍`), none next to full-width punctuation; full-width ，。？！：；（）、; quotes 「」, nested 『』; alternatives ` / `; ✗ / ✓ for wrong / right.
5. **Terms:** Taiwan school grammar term first, English in half-width parentheses at first mention in a lesson: 冠詞 (articles).

## 5. What to say about Taigi (the contrasts; profile §4 has the full list)
No articles; no plural (only 阮 / 𪜶 for people); verbs never change — **有 + verb** affirms a past event (「我有去」 is not *I have went*), 矣 marks a change, 咧 = in progress, 過 = experience. **伊** = he, she and it. 欲 = want and going to; 會 = will and can; 予 = give, let and the passive agent (予人 + verb); 共 has no English form. Adjectives need *be* (伊真媠 → *She is very pretty*); 真 + verb ≠ *very* + verb. 有 = have and there is. 看 = see / look / watch / read; 講 = say / tell / speak / talk; 借 = lend / borrow. Time and place go before the verb in Taigi, after it in English. Sounds: no f (→ h / hu), no v (→ b), no θ ð, no ʃ (*she* ~ *see*), no r (→ l), n / l one sound, finals only -p -t -k -h -m -n -ng (no -b -d -g -s -z -l, extra vowels in clusters); Taigi **has** voiced b / g (an advantage over Mandarin). Japanese-era loans with extra vowels (bì-lù beer, bá-suh bus) show what to avoid. Taiwan schools teach American English with KK, so no British-school notes.

## 6. Pron (KK, tool-made)
Never hand-type. Write the zh-style IPA (Grep yue/zh for the same English), run `node tools/content/nan/kk.js "/ˈkʌp əv ˈkɔːfi/"`, paste the output (`/ˈkʌp əv ˈkɔfɪ/`). KK symbols: i ɪ e ɛ æ ɑ ɔ o ʊ u ʌ ə ɝ ɚ aɪ aʊ ɔɪ, ḷ ṇ; stress ˈ ˌ; no ː. Prose symbols are KK too (/ɛ/ = *bed*, /e/ = *day*). `kk.js --check` must be clean. Never run `kk.js --files`. Names: Taiwan /ˌtaɪˈwɑn/, Taipei /ˌtaɪˈpe/, Tainan /ˌtaɪˈnɑn/, Lin /ˈlɪn/, Jay Chou /ˌdʒe ˈtʃo/.

## 7. Standing rule
`article-plural`, keywords **冠詞|複數**: in every practice set at least half the `order` and half the `type` items hinge on an article or plural, and their `why` contains 冠詞 or 複數 (「two 後壁的名詞愛用複數：brothers。」, 「頭一擺提著用 a，第二擺用冠詞 the。」). The scaffold's 眾數 fails the validator.
