# Hmong research sources (opened 2026-11-23)

Research step for `hmn-en` and `en-hmn` (White Hmong, RPA). Every source id below was **opened in this session**, and every glossary row cites only sources whose returned text contained that headword.

**How the sources were read (this limits everything).** Direct downloads (curl) to every Hmong source were refused by the session's network proxy. All reading went through the WebFetch tool, which returns a summary written by a small model, not the raw page. In practice:
- Long lists came back only when requested in chunks ("rows 1–70", "one line per sense").
- On some pages the tool refused to copy long lists, or skipped a page because it saw an instruction in the page text (kaikki `qa…` page, Brainscape classifiers deck).
- Glosses are sometimes paraphrased ("glosses paraphrased" was stated for one kaikki verb page).
- A few returned glosses were clearly wrong. These were dropped or flagged in the glossary note: Whitelock `tagkis` returned as "morning", `nrog` as "from", `las` as "and". The NCELA toolkit's English glosses were the tool's own translation and were not used at all.

So treat every row as "**attested spelling, approximately attested gloss**".

**Counts.** 1,274 glossary headwords from 28 source ids. 987 rows rest on **one** source id and 287 on two or more. Wiktionary (through kaikki.org, W-KK, plus the Swadesh appendix, W-SW) supports 654 + 212 row-citations. **More than half of the glossary rests on Wiktionary read through a summariser.**
