# yue interface notes (writer I)

Source: `tools/i18n/zh/ui.json`, converted to Traditional (zhconv `zh-hk`, run from a scratch folder), then the profile §10 wording table, then every string read and corrected by hand. Register: Hong Kong written Chinese (書面語), 你, 「」 quotes.

Decisions
- Character forms: 溫 (not 温), 帳戶 / 用戶 (not 户), 說, 閱, 啟, 裏, 着, 敍, as the profile writes them.
- Counts: one wording per pattern, classifier after the number; singular and plural templates are identical. 日 for days, 星期 for weeks, 第 {n} 級 for levels.
- Streak: 連續日數 (label), 連續紀錄 (the thing that can break), 連續護盾 (streak shield). No 打卡.
- due = 待溫習; "Review due cards" = 溫習到期的卡片 (avoids 溫習待溫習).
- phrase = 短句 ("My phrases" = 我的短句); words on tiles = 字詞; words learned = 生字.
- Feedback tab = 意見; "Vibration feedback" = 震動回饋 (haptics, a different sense).
- Undo and restore are both 還原 (profile table); "Reset to defaults" = 重設為預設值.
- Greetings: 早安 / 午安 / 晚上好 (晚安 means good night).
- Level titles: 萌芽, 學員, 前輩, 高手, 大師, 宗師; 入門, 話匣子, 旅行者, 本地通.
- Roadmap: only the 39 English-roadmap titles are filled. The basis line keeps the key's meaning ("adjusted for Korean speakers" = 按韓文母語者的需要調整).
