# en-nan Core words, Flirting and Compliments: sources and choices

Writer EN-NAN-T, 2026-11-23. Files: `decks-t.js` + `extra-t.js` (eleven Core words decks), `decks-f.js` + `extra-f.js` (Flirting), `decks-c.js` + `extra-c.js` (Compliments), `lexicon-add-T.txt` (12 new readings).

## 1. Frequency: no Taigi frequency list could be opened, so every deck is ordered by judgement

What was tried (2026-11-23):

| Tried | Result |
|---|---|
| Web search: Taiwanese Hokkien / Taigi frequency list, corpus word list | Found only the Wikipedia page on the MOE *Dictionary of Frequently-Used Taiwanese Taigi* (a dictionary of common words with no ranking), and two Hugging Face sets |
| `taiwan-corpora/twngrams` (Hugging Face), opened | It holds n-gram counts for Taiwan **Mandarin** (HPLT `cmn_Hant`), not Taigi. Not used |
| `Bohanlu/iCorpus-100` (Hugging Face), opened | 100 parallel Taigi news sentences: too small to rank words, and its files could not be downloaded (proxy 403). Not used |
| Yang et al., *Modeling Taiwanese POS tagging…* (ROCLING 2008, aclanthology O08-1012), opened | It uses a 2.58-million-syllable Taigi literature corpus but prints no word frequency list. Not used |
| Wiktionary: Frequency lists (en.wiktionary.com mirror), opened | Has no Min Nan / Hokkien / Taiwanese list |
| MOE dictionary category indexes (sutian.moe.edu.tw `hunlui/98–102`) | Not frequency lists. They could not be fetched in this session anyway, because the web tool refused sutian pages that a search had not returned |

**So no rank in any deck comes from a source.** Words were chosen from the course lexicon (`lexicon.txt` and the `lexicon-add-*` files) by what an A1 learner meets first. Each deck is sorted by the writer's judgement of everyday use, most useful first, taking the course profile's lesson order into account. A native speaker should reorder freely.

## 2. Pronunciation and the lexicon

- Every `pron` was generated by `tools/target/nan/respell.js` in the build script and pasted unchanged. `repron.js nan` rewrote 0 on both runs.
- Every EXAMPLES and DIALOG sentence also goes through `respell.js` without a throw, so every word in them is in the lexicon.
- **12 new words** are in `lexicon-add-T.txt`: 因為, 所以, 雖然, 了後, 而且, 對, 對面, 邊仔, 中央, 古錐, 目睭, 認真.
  - Each was read off an English Wiktionary page (the kiwix mirror kaweah.freedombox.rocks, 2023-04 dump), named per line, through a web tool that returns a summary. The MOE entry pages themselves could not be fetched (see above).
  - 所以 (só͘-í), 而且 (jî-chhiáⁿ) and 對 (tùi) were given in POJ only and are written in Tâi-lô with the MOE manual's mapping (o͘ → oo, chh → tsh, ⁿ → nn). 中央 (tiong-ng) is the same in POJ and Tâi-lô.
  - 雖然 and 認真 have a Kaohsiung reading (kept: sui-jiân, jīn-tsin) and a Taipei one (sui-liân, līn-tsin). 邊仔 is *pinn--á* (neutral á) in all the Taiwan accents listed.
  - **No reading is `unverified:model`.** None was typed from memory.
- **Words left out because no opened source gave their reading** (wanted, but cut):
  - Flirting: 緣投 (handsome), 佮意 (like), 笑 (smile), 𠢕 alone (capable), 頭毛 (hair), 溫柔 (gentle), 趣味 (fun), 好心 (kind-hearted), 巧 (clever; the Wiktionary page gives three readings and no clear Taiwan sense).
  - Compliments: 呵咾 (praise), 有心 (thoughtful), 猶閣 (still), 加 (more); 領 replaced by the course's 件 for clothes.
  - Interjections: 哎唷, 害矣, 好佳哉, 莫怪, 喂, 哇, 唉 (the Wiktionary pages opened show no Hokkien reading).
  - Prepositions: 替, 為著, 內底.
  - Example sentences: words like 嘛 (alone), 也, 等, 走, 緊, 提, 洗, 間, 擔 (alone), 閒 (alone), 一屑仔 were avoided by rewording.

## 3. Class slots renamed or added (brief rule 2)

| Slot | What this course does | Why |
|---|---|---|
| `Top prepositions` | The name is kept. It holds coverbs (共, 比, 對, 用, 到, 甲, 親像) and place words that follow the noun (對面, 邊仔, 中央, 下, 倒爿) | Taigi marks place and direction with verb-like words before the verb (佇, 共, 對) and with place words after the noun (公園邊仔). |
| `Top adjectives` | Kept, with the note "No 是 before an adjective" | Taigi adjectives work like verbs (伊真媠, not *伊是媠), as in the profile (§4.2) |
| `Top interjections` | Kept, filled with short exclamation and reply words (有影, 毋著, 小心, 無法度…) | Sound-words like ouch / wow (哎唷, 哇) could not be sourced. This is the deck to grow first once the MOE 助詞、嘆詞 index can be opened |
| **`Top measure words`** (added) | 19 more classifiers, one per card | Taigi has classifiers, like Mandarin and Cantonese. The course already has a `Classifiers` deck, but it teaches phrases (兩本冊), so here the classifier stands alone. Descriptions and notes say "classifier", as the profile glossary requires |
| **`Top particles`** (added) | 12 cards: 矣, 啦, 咧, 無, 未, 袂, 敢, 的, 仔, 過, 一下, 著 | The course's `Questions and particles` deck holds whole sentences. This deck gives each particle alone, with the reading the tool prints for it alone (咧 = teh, 無 = bô) and the context reading in the note |

## 5. Flirting and Compliments

- **Flirting** starts from `docs/plans/compliments-nan.md` Deck 2. It has three layers:
  - Words: 古錐, 目睭, 𨑨迌, 見面, 感情, 牽手. Only 6, because 緣投, 佮意, 笑 and 𠢕 could not be sourced; 媠, 好看 and 歡喜 are already cards.
  - Phrases: 8, built from 媠, 好看, 古錐, 目睭 and 歡喜.
  - Moves and replies: 14 (the number request is 你的電話敢會使予我？), including a warm yes (好，咱來去！), a playful deflection (你真會講話。) and three clear, kind noes (多謝，毋過咱做朋友就好。 / 歹勢，我有牽手矣。 / 多謝你，毋過我無愛。).
  - Open flirting is indirect in Taiwan [inference]: interest is usually shown by inviting someone to eat, drink tea or 𨑨迌, which is what the moves layer teaches.
  - Left out: plan rows 2, 3, 5, 12, 13, 16 and 18 (緣投, 笑, 特別, 想, 佮意, 𠢕, 對象 are not in the lexicon); "I love you".
- **Compliments** is built from plan Deck 1. It drops rows 3, 7, 8, 9, 10, 18, 19 and 20 (𠢕, 好心, 趣味, 巧, 有心, 哪有, 猶閣, 呵咾 not sourceable) and adds praise for clothes (你穿這件衫真好看。), thanks for a gift (這个禮物真媠，多謝你！), 你真客氣。 and the replies 有影無？ and 你傷客氣矣。
