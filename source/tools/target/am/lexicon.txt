# Romanisation key (profile docs/profiles/en-am.md section 6). One spelling per fidel unit, no context rules:
#   vowel orders: 1st e (ደ de), 2nd u, 3rd i, 4th a, 5th é (ቤ bé), 6th i where the source says it is pronounced, nothing where it is silent, 7th o.
#   ሀ ሐ ኀ አ ዐ: first order is a (Addis Ababa merger, LDC note). Labialised -wa letters: bwa, lwa, kwa, gwa, k'wa.
#   consonants: sh ሸ, ch ቸ, j ጀ, zh ዠ, ny ኘ (and ኝ), y የ, w ወ, v ቨ.
#   ejectives take an apostrophe: t' ጠ, k' ቀ, p' ጰ, ch' ጨ, ts' ጸ/ፀ (as BGN/PCGN; most speakers say it as an ejective ts).
#   a glottal stop between vowels (ዓ, ዕ inside a word) is an apostrophe after the vowel: se'at, bi'ir.
#   gemination (a long consonant, never written in fidel) is a doubled letter: bunna, abbat; for a two-letter consonant the first letter
#   doubles: ssh, cch, nny, tt', kk', cch'. Taken from the source named on the line. A final long consonant is written only where the source writes it (birr, widd).
#   Prefixes ከ- በ- ለ- የ- are joined to the word with no hyphen (keamérika).
#
