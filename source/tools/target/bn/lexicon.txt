# How a printed form becomes this key (mechanical; a line counts as verified only if it is this conversion of what the page printed):
#   Wiktionary tables: ô -> ô, ê -> æ, ō -> o, c -> ch, ch -> chh, cc -> cch, cch -> cchh, ĵ -> j, ẏ -> y, ś -> sh, oẇa / ōẇa / ōẏa -> oya, kkh stays kkh.
#   Wiktionary IPA: ɔ -> ô, o -> o, æ / ɛ -> æ, ʃ -> sh, t̪ d̪ -> t d, ʈ ɖ -> ṭ ḍ, ɹ / ɾ -> r (ṛ where the spelling has ড় ঢ়), ʰ ʱ -> h, Cː -> CC.
#   MSU: O -> ô, E -> æ, T -> ṭ, D -> ḍ, R -> ṛ, c -> ch, ch -> chh; a nasal the spelling marks with ঁ gets its tilde from the spelling.
#     MSU's lowercase o is not trusted for ô versus o (it prints ponero, shottor): those lines are unverified:model.
#   UT: ɔ -> ô, c -> ch, ch -> chh, T -> ṭ, D -> ḍ, dʰ -> dh, khkh -> kkh (geminate aspirate rule of the key).
#   Wikivoyage: aw -> ô, oh -> o, a / ack -> æ, ah -> a, ih -> i, oo -> u, eh -> e, rr -> ṛ, tt -> ṭ, dd -> ḍ, n before a consonant after a vowel the spelling marks with ঁ -> tilde.
#   Consonant letters, ঁ and hyphens always follow the spelling (the key writes every letter's own value); the source decides the vowels,
#   whether an inherent vowel is said, ô versus o, e versus æ, s versus sh, and doubling.
