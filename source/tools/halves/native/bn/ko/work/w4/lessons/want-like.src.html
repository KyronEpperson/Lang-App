Two of the most useful patterns in any language. "Want to" attaches to a verb; "like" takes a noun.

Want to: stem + 고 싶어요

Drop 다 and add 고 싶어요. There is no vowel rule to think about.

Add what and where in front

The rest of the sentence stays the same; only the verb ending changes.

{{ex:ko.s0168}}{{ex:ko.s0169}}{{ex:ko.s0170}}

Don't want to, wanted to

Put 안 in front, or change 싶어요 to the past.

{{ex:ko.s0171}}{{ex:ko.s0172}}

Like: noun + 을/를 좋아해요

좋아해요 is an action verb ("to like"), so the thing you like takes 을/를. Its cousin 좋아요 ("is good") is a describing verb, so it takes 이/가.

{{ex:ko.s0173}}{{ex:ko.s0174}}{{ex:ko.s0175}}{{ex:ko.s0176}}
To want a thing, Koreans usually name the action: "I want coffee" is 커피 마시고 싶어요, or simply 커피 주세요.
Common mistakes
  • 가다고 싶어요 ✗ → 가고 싶어요 ✓ (drop 다 first)
  • 가요 싶어요 ✗ → 가고 싶어요 ✓
  • 커피가 좋아해요 ✗ → 커피를 좋아해요 ✓
  • 커피를 좋아요 ✗ → 커피가 좋아요 ✓
