English describes with "is": "He is tall", "It is hot". Cantonese has no "is" here. Adjectives work like verbs: they follow the person or thing directly, with no 係 hai6.

No 係, and 好 as glue

A plain description usually takes 好 hou2 in front of the adjective. Often it is just glue, not a strong "very". Without it, a bare adjective tends to sound like a comparison: 佢高 suggests "he's the taller one", so the everyday description is 佢好高.

{{ex:yue.s0179}}{{ex:yue.s0180}}

So 好 is not only "good": 好平 hou2 peng4 means "really cheap", not "good and cheap".

{{ex:yue.s0181}}

Not, and asking

For "not", put 唔 straight before the adjective and drop the 好: 唔貴 m4 gwai3 is "not expensive". To ask, use the verb-not-verb question from lesson 7: adjectives work like verbs, so 貴唔貴.

{{ex:yue.s0182}}

Too, quite, so, so-so

CantoneseMeaning
太貴too expensive
幾好quite good, pretty good
唔係幾好not very good
咁貴so expensive
麻麻哋so-so

太 taai3 is "too", 幾 gei2 is "quite", 咁 gam3 is "so", and 麻麻哋 maa4 maa2 dei2 is a polite "so-so".

{{ex:yue.s0183}}{{ex:yue.s0184}}

Comparing with 過

English says "taller than me". Cantonese says the adjective, then 過 gwo3, then the other person or thing: literally "tall-pass me". The order never changes: adjective, 過, the other one. There is no word for "more": 過 already does that job.

{{ex:yue.s0185}}{{ex:yue.s0186}}

A bit more: 啲

Adjective + 啲 di1 is "a bit more": 平啲 (a bit cheaper), 大啲 (a bit bigger), 細啲 (a bit smaller). It is handy when shopping, as in 平啲得唔得呀？ (could you make it a bit cheaper?) from the shopping lesson.

{{ex:yue.s0187}}

A describer before the noun

To put a description in front of a noun ("a really nice top"), add 嘅 ge3 and keep the order of English: describer, 嘅, noun. A counted thing still takes its classifier at the front.

{{ex:yue.s0188}}{{ex:yue.s0189}}
Most common mistake: putting 係 before an adjective, the way English uses "is". 佢係高 → 佢好高.
