唔使……

呢個係另一個句式：안 + 刪走 요 嘅 요體 + 도 돼요，字面意思係「唔……都得」，啱啱就係廣東話嘅「唔使」。

{{ex:ko.s0272}}{{ex:ko.s0273}}
唔加 안，同一個詞尾就表示准許，即係「……得唔得」：가도 돼요? =「我走得唔得？」第 32 課「有禮貌咁請求」會用到。
常見錯誤
  • 먹야 해요 ✗ → 먹어야 해요 ✓（由 먹어요 開始）
  • 하야 해요 ✗ → 해야 해요 ✓
  • 「唔使去」講成 안 가야 해요 ✗ → 안 가도 돼요 ✓
  • 「當時要去」講成 갔어야 해요 ✗ → 가야 했어요 ✓
