에 同 에서 都係黐喺地方後面，廣東話好多時兩個都講「喺」。分別喺動詞。에 配去、嚟同喺某處，仲有時間。에서 配喺某個地方做嘢，同埋「由」。用廣東話測試：「喺」+ 喺度（喺屋企）→ 에；「喺」+ 做嘢（喺咖啡店溫書）→ 에서；「去 / 嚟」+ 地方 → 에；「由……嚟」→ 에서。

에：去邊

目的地 + 에，配 가요（去）同 와요（嚟）。

에서：喺邊度做嘢，同「由」

喺某個地方做動作，就用地方 + 에서：食嘢、溫書、休息、返工。配 왔어요 就係「由」。

快速測試：睇動詞。가요、와요、있어요、없어요 → 에。喺嗰度主動做嘅嘢（먹어요、공부해요、쉬어요）→ 에서。
常見錯誤
  • 目的地用 에서：집에서 가요 ✗ → 집에 가요 ✓
  • 動作用 에：카페에 공부해요 ✗ → 카페에서 공부해요 ✓
  • 있어요 配 에서：집에서 있어요 ✗ → 집에 있어요 ✓
  • 助詞擺喺名詞前面（好似廣東話「喺屋企」咁）：에 집 ✗ → 집에 ✓
