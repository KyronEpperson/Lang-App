韓文好少講「你」，對比自己大嘅人更加差唔多唔會直接叫名。叫人要用職位、身份或者親屬稱呼。

講法對邊個例子
이름 + 씨同輩、同事，有禮貌嘅預設叫法민수 씨、지은 씨
직함 + 님有職位、身份嘅人，客人선생님、사장님（老闆）、고객님
오빠 / 형大過你嘅男仔（女仔叫 / 男仔叫）민수 오빠、민수 형
언니 / 누나大過你嘅女仔（女仔叫 / 男仔叫）지은 언니、지은 누나
淨係叫名 + 아/야只限好朋友同細過你嘅人민수야!、지은아!

아 / 야 規則

直接叫好朋友個名：名以元音結尾就加 야（민수 → 민수야!），以收音結尾就加 아（지은 → 지은아!）。

唔肯定嗰陣，對同輩喺全名後面加 씨 一定唔會錯。留意：선생님 係「老師」，唔係廣東話嘅「先生」；사장님 就好似「老闆」，餐廳、小店都咁叫。오빠 / 형、언니 / 누나 要睇講嘢嗰個人係男定女，唔似「阿哥」、「家姐」咁人人都一樣叫。自己個名後面永遠唔加 씨，對大過你嘅人永遠唔用 야。
