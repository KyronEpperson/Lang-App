原形用 다 收尾：가다（去）、먹다（食）、하다（做）。斬走 다 得到詞幹，再加禮貌詞尾。呢一個形式就包晒「我去」、「我去緊」同「你去唔去？」。

睇最後一個元音揀詞尾

睇詞幹嘅最後一個元音：

最後元音加例子
ㅏ 或者 ㅗ아요가다 → 가요 · 보다 → 봐요
其他어요먹다 → 먹어요 · 마시다 → 마셔요
하다 動詞해요하다 → 해요 · 공부하다 → 공부해요

元音會合埋

詞幹用元音收尾嘅話，兩個元音會溶埋一齊：가 + 아요 = 가요，오 + 아요 = 와요，마시 + 어요 = 마셔요。

收音詞幹直接加

詞幹有收音，就冇嘢要合。

一個形式，幾種用途

陳述、問題、「而家做緊」都係同一個字。問嘢淨係語調升高，唔使好似廣東話咁講「去唔去」。

{{ex:ko.s0083}}{{ex:ko.s0084}}{{ex:ko.s0085}}{{ex:ko.s0086}}
講「唔」，就將 안 擺喺動詞正前面：안 가요（唔去）。跟住兩課分別講過去式同將來式。
常見錯誤
  • 가아요 ✗ → 가요 ✓（元音合埋）
  • 먹아요 ✗ → 먹어요 ✓（ㅓ 用 어요）
  • 하어요 ✗ → 해요 ✓（하다 好特別）
  • 講原形：저는 가다 ✗ → 저는 가요 ✓
