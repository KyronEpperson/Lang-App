任何語言都最好用嘅兩個句式。「想」接動詞；「鍾意」接名詞。廣東話都係咁：「我想去」、「我鍾意咖啡」。

想：詞幹 + 고 싶어요

刪走 다，加 고 싶어요。唔使諗元音規則。

鍾意：名詞 + 을/를 좋아해요

좋아해요 係動詞（「鍾意」），所以你鍾意嘅嘢用 을/를，同廣東話「鍾意咖啡」一樣，咖啡係賓語。佢嘅親戚 좋아요（「好」）係形容詞，所以用 이/가，好似「咖啡好好」。

{{ex:ko.s0173}}{{ex:ko.s0174}}{{ex:ko.s0175}}{{ex:ko.s0176}}
想要一樣嘢，韓國人通常會講出個動作：「我想要咖啡」係 커피 마시고 싶어요，或者乾脆講 커피 주세요，即係「唔該要咖啡」。
常見錯誤
  • 가다고 싶어요 ✗ → 가고 싶어요 ✓（先刪走 다）
  • 가요 싶어요 ✗ → 가고 싶어요 ✓
  • 커피가 좋아해요 ✗ → 커피를 좋아해요 ✓
  • 커피를 좋아요 ✗ → 커피가 좋아요 ✓
