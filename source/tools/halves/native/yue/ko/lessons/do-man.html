도 即係「都 / 亦都」，만 即係「淨係」。兩個都好似其他助詞咁，黐喺名詞後面。廣東話嘅「都」同「淨係」擺喺動詞前面（我都去），韓文就黐住個名詞：저도 即係「我都」。要學嘅規則得一條：佢哋會取代 은/는、이/가 同 을/를，但係喺 에 同 에서 後面就疊上去。

도 = 都、亦都

邊樣嘢「都」係咁，就將 도 黐喺嗰樣嘢後面。

도 取代 은/는、이/가、을/를

原本嘅助詞拎走，換 도 上去。永遠唔好疊埋一齊。

만 = 淨係

만 用法一樣：取代 은/는、이/가、을/를。이것 係 이거（呢個）嘅完整講法。

{{ex:ko.s0149}}{{ex:ko.s0150}}{{ex:ko.s0151}}{{ex:ko.s0152}}

喺 에 同 에서 後面就疊上去

에 同 에서 有自己嘅意思（去、喺、由），所以要留低，도 / 만 跟喺後面。

{{ex:ko.s0153}}{{ex:ko.s0154}}{{ex:ko.s0155}}
도 + 否定即係「都唔」：저도 안 가요 = 我都唔去，同廣東話「都唔」一樣次序。저도요（我都係）係加入任何對話最簡單嘅一句。
常見錯誤
  • 도 疊喺 은/는 上面：저는도 ✗ → 저도 ✓
  • 만 疊喺 을/를 上面：커피를만 마셔요 ✗ → 커피만 마셔요 ✓
  • 漏咗 에：집도 있어요（= 我都有間屋）✗ → 집에도 있어요 ✓
  • 次序錯：학교도에서 ✗ → 학교에서도 ✓
