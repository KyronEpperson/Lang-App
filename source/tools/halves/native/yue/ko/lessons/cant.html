「唔」你已經識用 안 講。「做唔到」喺韓文係另一個字：못，即係廣東話嘅「……唔到」（食唔到、去唔到）同「唔識」。「可以」就用句式 -(으)ㄹ 수 있어요，否定係 -(으)ㄹ 수 없어요。再加兩個講「唔知」嘅方法，你就可以有禮貌咁拒絕任何嘢。

안 = 唔（唔想），못 = 做唔到

兩個都緊貼喺動詞前面。照意思揀：係自己揀唔做（안），定係有原因做唔到（못）。廣東話「唔食辣」同「食唔到辣」就係呢個分別。

하다 動詞要拆開，同 안 一樣

못 擺喺名詞同 해요 中間，唔講 못 공부해요。

可以：-(으)ㄹ 수 있어요 / 없어요

元音後面用詞幹 + ㄹ 수 있어요，收音後面用 을 수 있어요。換做 없어요 就係「唔可以 / 做唔到」。廣東話嘅「可以」、「識」、「……得」都可以用佢嚟講。

몰라요 同 모르겠어요

몰라요 = 唔知（某件事）。모르겠어요 = 唔太清楚 / 唔明，語氣軟啲，人哋問你嘢嗰陣更常用。肯定講法係 알아요。「唔知」本身係一個獨立動詞，唔係 안 + 알아요。

{{ex:ko.s0262}}{{ex:ko.s0263}}{{ex:ko.s0264}}
畀人問 매운 거 먹을 수 있어요?（你食唔食得辣？）差唔多係必經一關。答 네, 잘 먹어요 會令人刮目相看；조금요（少少）係老實嘅答案。另外，한국어 잘 못해요（我韓文唔係好叻）入面嘅 못해요 解「唔擅長」，要寫埋一個字。
常見錯誤
  • 못 擺喺 하다 動詞嘅名詞前面：못 공부해요 ✗ → 공부 못 해요 ✓
  • 做唔到都用 안：辣到頂唔順都講 매운 거 안 먹어요 ✗ → 매운 거 못 먹어요 ✓
  • 收音後面漏咗 을：먹 수 있어요 ✗ → 먹을 수 있어요 ✓
