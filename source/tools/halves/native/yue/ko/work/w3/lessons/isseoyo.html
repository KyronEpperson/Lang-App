廣東話分得好清楚：「我係學生」用「係」，「我喺屋企」用「喺」，「我有隻貓」用「有」。韓文將後面兩個合埋：이에요/예요 講某樣嘢「係」乜；있어요 就包晒「有」同「喺」：有某樣嘢、某樣嘢喺邊度、你擁有某樣嘢。佢嘅相反係 없어요，即係「冇」同「唔喺」。兩個短短嘅動詞，你已經問得到一半要用嘅嘢。

有、冇

있어요 = 有 / 有冇？；없어요 = 冇。問嘅時候語調升高，答就用返同一個動詞，好似廣東話「有冇？——有。」

主格助詞 이/가

存在嘅嘢，收音後面加 이，元音後面加 가。

{{ex:ko.s0049}}{{ex:ko.s0050}}{{ex:ko.s0051}}

擁有

韓文講「講到我呢，有 X」。擁有者用話題 은/는，嘢用 이/가。廣東話「我有貓」嘅重點都係「有」。

{{ex:ko.s0052}}{{ex:ko.s0053}}{{ex:ko.s0054}}

喺邊度：地方 + 에

地方後面加 에，然後講 있어요 或者 없어요。「隻貓喺屋企」嘅「喺」，韓文都係 있어요。

{{ex:ko.s0055}}{{ex:ko.s0056}}{{ex:ko.s0057}}{{ex:ko.s0058}}

이에요 定 있어요？

句子係「A = B」（廣東話用「係」），就用 이에요/예요。講喺邊度或者有乜嘢（廣東話用「喺」或者「有」），就用 있어요。

廣東話韓文點解
我係學生학생이에요係：我 = 學生
我喺學校학교에 있어요喺：位置
呢度係學校여기는 학교예요係：呢度 = 學校
呢度有間學校여기에 학교가 있어요有：存在
講嘢嗰陣，短問句通常會省略 이/가：시간 있어요?（得唔得閒？）先係大家真正嘅問法。不過讀嘢同砌長句，仍然要識 이/가。
常見錯誤
  • 講位置要用 있어요：完整講法係 저는 학교에 있어요 ✓（口語入面你都會聽到 지금 학교예요，「我而家喺學校」）
  • 擁有用 이에요：저는 고양이예요 ✗（= 我係一隻貓）→ 저는 고양이가 있어요 ✓
  • 이/가 用錯：시간가 있어요 ✗ → 시간이 있어요 ✓
  • 漏咗 에：고양이가 집 있어요 ✗ → 고양이가 집에 있어요 ✓
