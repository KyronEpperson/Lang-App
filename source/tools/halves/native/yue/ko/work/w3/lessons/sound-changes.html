韓文嘅寫法係為咗顯示意思，講嘅時候就會順口啲。所以 감사합니다 讀落似「gamsahamnida」，唔係「hap-ni-da」。四個習慣解釋到差唔多所有意外。呢個程式嘅羅馬拼音大致跟讀音寫（不過緊音化唔會寫出嚟）。

先講你嘅優勢：收音你已經識六個。韓文音節用 7 個音收尾：k、n、t、l、m、p、ng。廣東話有其中 6 個，淨係 l 係新嘢。k、t、p 唔爆破，同「學（hok6）」、「物（mat6）」、「鴨（aap3）」一樣；l 就要用舌尖貼住上齒齦，唔好讀成「一（jat1）」嘅 t。韓文冇聲調：唔好將廣東話聲調加落每個音節，高低屬於成句。

1 · 連音：收音滑去下一格

下一個音節塊用唔發音嘅 ㅇ 開頭，收音就會搬入嗰個空位。收音只讀一次：hangugeo = han-gu-geo。

2 · 鼻音化：ㅂ ㄷ ㄱ 喺 ㄴ 同 ㅁ 前面變軟

喺 ㄴ 或者 ㅁ 前面，ㅂ 變 ㅁ，ㄷ 變 ㄴ，ㄱ 變 ㅇ（ng）。用廣東話收音去諗：p → m、t → n、k → ng，口形唔變，只係氣改由鼻出，好似「十（sap6）」嘅 p 同「三（saam1）」嘅 m 都係閉埋嘴唇。

3 · ㅎ：會噴氣，或者消失

ㅎ 喺 ㄱ ㄷ ㅂ ㅈ 隔籬，會將佢哋變成送氣嘅 ㅋ ㅌ ㅍ ㅊ。喺兩個元音中間，ㅎ 唔發音。

4 · ㄴ 遇到 ㄹ：兩個都變 ㄹ

ㄴ 同 ㄹ 擺埋一齊，就讀成一個長長嘅 l。

常見錯誤
  • 逐格讀：gam-sa-hap-ni-da ✗ → gamsahamnida ✓
  • 喺 ㅇ 前面停一停：han-guk-eo ✗ → hangugeo ✓
  • 讀出 좋아요 嘅 ㅎ：jo-ha-yo ✗ → joayo ✓
  • 聽到點讀就點寫：조아요 ✗ → 좋아요 ✓（寫法永遠唔變）
