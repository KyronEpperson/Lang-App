想講「唔做」某件事，將 안 擺喺動詞正前面就得，大部分否定句咁樣就搞掂。廣東話「唔 + 動詞」係 안 + 動詞；「冇 + 動詞」（我冇去）就係 안 + 過去式，唔係 없어요。另外有個長啲嘅講法 -지 않아요，意思一樣。有兩種情況唔同：名詞用 아니에요（唔係），而 있어요 嘅否定係另一個動詞 없어요（冇）。

안 + 動詞

안 直接擺喺動詞前面，喺賓語後面，永遠唔會喺賓語前面。呢點同廣東話唔同：「唔」管住成個「飲咖啡」，擺喺賓語前面；안 只係黐住後面嗰一個動詞，好似講「咖啡唔飲」。

하다 動詞要拆開

名詞 + 하다 嘅動詞，안 擺喺名詞同 해요 中間。좋아해요 唔係名詞 + 하다，所以唔拆。

{{ex:ko.s0134}}{{ex:ko.s0135}}{{ex:ko.s0136}}

-지 않아요

詞幹 + 지 않아요。意思同 안 一樣，聽落稍為認真啲，書面語好常見。過去式：지 않았어요。

{{ex:ko.s0137}}{{ex:ko.s0138}}{{ex:ko.s0139}}

名詞同 있어요 有自己嘅否定

「唔係……」係 이/가 아니에요。「冇 / 唔喺度」係 없어요，永遠唔講 안 있어요。呢度同廣東話一樣：「唔係」同「冇」本身就係兩個講法。

常見錯誤
  • 안 擺喺 하다 動詞嘅名詞前面：안 공부해요 ✗ → 공부 안 해요 ✓
  • 안 擺喺賓語前面（照搬「唔飲咖啡」）：안 커피를 마셔요 ✗ → 커피를 안 마셔요 ✓
  • 안 配 있어요：시간이 안 있어요 ✗ → 시간이 없어요 ✓
  • 안 配名詞：학생 안 이에요 ✗ → 학생이 아니에요 ✓
