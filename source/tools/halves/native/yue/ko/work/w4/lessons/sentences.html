名詞、動詞、助詞你都識晒。初學者講嘅句子，差唔多全部都係以下四種句型之一，而且動詞永遠喺最後。

1 · A 係 B

名詞 + 이에요 / 예요。

{{ex:ko.s0059}}

2 · A 係點（形容）

名詞 + 이/가 + 形容詞。

{{ex:ko.s0156}}

3 · 對 A 做某件事

名詞 + 을/를 + 動詞。

{{ex:ko.s0112}}

4 · 去 / 喺 / 喺度做嘢

地方 + 에，配 가요、와요、있어요。喺嗰個地方做嘢，就用地方 + 에서。

{{ex:ko.s0157}}{{ex:ko.s0126}}

一步步加長

由動詞開始，向前面加嘢。一般次序：邊個 · 幾時 · 同邊個 · 喺邊 · 乜嘢 · 動詞。廣東話本身都差唔多係咁排（我今日同朋友喺咖啡店飲咖啡），只係「乜嘢」同動詞要調轉。

{{ex:ko.s0158}}{{ex:ko.s0112}}{{ex:ko.s0159}}{{ex:ko.s0160}}

換零件

框架唔變，換一個字。一句就係咁變成五十句。

{{ex:ko.s0161}}{{ex:ko.s0162}}{{ex:ko.s0163}}{{ex:ko.s0164}}
講到一半卡住？先講你識嘅名詞，最後先講動詞。反正韓國人都係等到個動詞先知你講乜。
常見錯誤
  • 照廣東話語序：저는 마셔요 커피를 ✗ → 저는 커피를 마셔요 ✓
  • 形容詞配 을/를：커피를 맛있어요 ✗ → 커피가 맛있어요 ✓
  • 做嘢嘅地方用 에：카페에 공부해요 ✗ → 카페에서 공부해요 ✓
