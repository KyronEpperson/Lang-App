講短句冇問題，但係將句子駁埋一齊，聽落先流利。下面每個詞尾都係用嚟取代前面嗰句嘅 요 詞尾。

-고 = 同埋、然後

詞幹 + 고。用嚟講兩件事（又……又……），或者先後兩個動作（……然後……）。

{{ex:ko.s0214}}{{ex:ko.s0215}}

-지만 = 但係

詞幹 + 지만，即係「雖然……但係……」。

{{ex:ko.s0216}}{{ex:ko.s0217}}

-아/어서 = 因為……所以……

先變成 요體，再將 요 換做 서。原因擺前面，同廣東話一樣。唔同嘅係，廣東話可以將原因擺後面（「我冇去，因為好忙」），서 就唔得。

{{ex:ko.s0218}}{{ex:ko.s0219}}

-아/어서 = 去（嚟）到之後……

配 가다、오다，將同一程嘅兩步駁埋：先去，再喺嗰度做嘢。

{{ex:ko.s0220}}{{ex:ko.s0221}}

時態擺喺最後嗰個動詞

-아/어서 永遠唔用過去式，由最後嗰個動詞話你知時間，好似「因為忙，所以冇去」咁，淨係後半句講明係過去。

{{ex:ko.s0222}}
兩句完整嘅句子之間，就用獨立嘅連接詞：그리고（同埋、跟住）、하지만 或者 그런데（但係）、그래서（所以）。下一課「用過去式講故事」就用佢哋嚟講故事。
常見錯誤
  • 바빴어서 ✗ → 바빠서 ✓（서 前面唔用過去式）
  • 싸요고 ✗ → 싸고 ✓（黐喺詞幹後面）
  • 비싸요지만 ✗ → 비싸지만 ✓
  • 搞亂咗：비싸서 맛있어요 即係「因為貴，所以好食」
