韓文數嘢用固有詞數字 + 量詞。量詞跟住你數緊乜嘢而變，好似廣東話「兩杯咖啡」、「三張紙」咁，一樣唔可以冇。真正唔同嘅係次序（睇下面）。

量詞數乜嘢例子
개嘢（通用），≈ 個사과 두 개
명 / 분人 / 人（尊敬），≈ 個 / 位세 명、세 분
잔杯커피 한 잔
병樽맥주 두 병
마리動物，≈ 隻강아지 한 마리
권書，≈ 本책 세 권
장扁平嘅嘢、飛，≈ 張표 두 장
살歲數，≈ 歲스물다섯 살
시간鐘頭（幾耐）두 시간
번次數，≈ 次세 번

1–4 嘅變化

喺量詞前面：하나 → 한，둘 → 두，셋 → 세，넷 → 네，스물 → 스무。其他數字唔變。廣東話喺量詞前面將「二」變「兩」，道理差唔多。

次序

名詞 + 數字 + 量詞：맥주（名詞）두（數字）병（量詞）。廣東話啱啱相反，講「兩樽啤酒」。有助詞嘅話，擺喺量詞後面：맥주 두 병을 마셨어요。

唔肯定？개 差唔多乜嘢都數得，好似廣東話嘅「個」，冇人會介意。不過數人永遠唔用 개（要用 명）。飲品嘅標準量詞係 잔，但喺咖啡店叫嘢，好多人都講 개。
常見錯誤
  • 飲品講 두 명 ✗：명 係數人，飲品用 잔。
  • 세 개 사람 ✗：照廣東話「三個人」嘅次序就錯，要講「名詞 + 數字 + 量詞」：사람 세 명。
  • 스물 살 ✗：스물 喺量詞前面變 스무：스무 살。
