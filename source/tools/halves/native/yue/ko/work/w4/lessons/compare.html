韓文形容詞比較嗰陣從來唔變形，只係加幾個細字：보다（比）、더（更、多啲）、덜（冇咁）同 제일（最）。

보다 = 比

보다 黐喺被比較嗰樣嘢後面。廣東話講「A 比 B 平」，韓文次序一樣：A、B、形容詞，只係「比」喺 B 前面，보다 喺 B 後面。如果你習慣講「A 平過 B」，就要記住：「過」喺形容詞後面，보다 就要黐喺 B 後面。더 加唔加都得，但好常用。

次序可以調轉

因為 보다 已經標明咗「比」嘅對象，兩個名詞可以調位。廣東話嘅「比」就唔可以咁搬。

{{ex:ko.s0245}}

더 = 更，덜 = 冇咁

佢哋緊貼喺形容詞前面，或者單獨配動詞用。

제일 = 最

가장 意思一樣，聽落正式少少。

叫人揀

呢度嘅 보다 係黐喺名詞後面嘅助詞，只係樣似動詞 보다（睇）。動詞會變（봐요），助詞永遠唔變。
常見錯誤
  • 보다 黐錯名詞：버스보다 택시가 싸요 即係的士平啲
  • 더 제일 맛있어요 ✗ → 제일 맛있어요 ✓（揀一個）
  • 택시 보다 ✗ → 택시보다 ✓（唔好留空格，佢係助詞）
  • 더 擺喺形容詞後面（照「平啲」咁排）：싸요 더 ✗ → 더 싸요 ✓
