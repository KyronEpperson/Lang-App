## Other glosses and terms set in lessons 16–28

- 碗 → tazón («un tazón de fideos») · 杯 → taza (té, café) / vaso (agua) · 瓶 → botella
- 来 + order (来两杯奶茶) → no person: «Dos tés con leche, por favor.»
- 请给我… (请给我一杯水) → no person: «Un vaso de agua, por favor.»
- 面条 → fideos · 奶茶 → té con leche · 果汁 → jugo · 房间 → habitación · 书包 → mochila
- 我明天去北京 / 明天我去北京 → Mañana voy a Pekín. (both; the lessons say they mean the same)
- 上班 → entrar a trabajar / ir al trabajo · 上课 → tener clase
- 坐 + vehicle → «ir en» (metro, autobús, avión) · 骑自行车 → «en bici» · 高铁 → tren de alta velocidad
- 兵马俑 → los Guerreros de Terracota · 长城 → la Gran Muralla
- Verb-not-verb glosses end in «…o no?» (你去不去 «¿Vas o no vas?», 你是不是老师 «¿Eres profesor o no?»), except 你有没有时间 (w1's gloss)
- 别 + verb → «no» + subjuntivo (别担心 «No te preocupes», 别走 «¡No te vayas!») · 不要说话 → «No hables.»
- 麻烦你… → «¿Me harías el favor de…?» (麻烦你说慢点儿 «¿Me harías el favor de hablar más despacio?», 麻烦你帮我一下 «¿Me harías el favor de ayudarme un momento?»)
- 你试试吧 → «¿Por qué no lo pruebas?» · 吧 with 我们 → «vamos a…» / «-emos» (Comamos)
- 我昨天很忙 → «Ayer estaba muy ocupado.» (imperfecto: no 了) · 我以前常常坐地铁 → «Antes tomaba mucho el metro.»
- 天气冷了 → «Ya hace frío.» · 我们到了 → «¡Ya llegamos!»
- 还没 + verb → «todavía no» + compound past («Todavía no he comido»)
- 还要 → «¿Algo más?» in body; 你还要什么 → «¿Qué más quieres?»
- Tip label in lesson bodies: «Error más frecuente:»
- Prompt cues used: «(da igual cuál)» for 或者; «(a un cliente, de usted)» for 您; «(a un amigo, con verbo-no-verbo)»; «(nunca aprendí)» for 不会; «me gustaría» for 想, «quiero» for 要
