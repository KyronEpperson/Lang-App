Las formas de diccionario terminan en 다: 가다 (ir), 먹다 (comer), 하다 (hacer). Quita 다 para sacar la raíz y agrega la terminación cortés. Esta única forma cubre «voy», «estoy yendo» y «¿vas?».

Elige la terminación según la última vocal

Mira la última vocal de la raíz:

Última vocalAgregaEjemplo
ㅏ o ㅗ아요가다 → 가요 · 보다 → 봐요
cualquier otra어요먹다 → 먹어요 · 마시다 → 마셔요
verbos con 하다해요하다 → 해요 · 공부하다 → 공부해요

Las vocales se funden

Cuando la raíz termina en vocal, las dos vocales se juntan en una sílaba: 가 + 아요 = 가요, 오 + 아요 = 와요, 마시 + 어요 = 마셔요.

Las raíces con consonante solo la agregan

Nada se funde cuando la raíz termina en consonante.

Una forma, muchos usos

Afirmación, pregunta y «ahora mismo» usan la misma palabra. Para preguntar solo cambia la entonación, igual que «vas» y «¿vas?».

{{ex:ko.s0083}}{{ex:ko.s0084}}{{ex:ko.s0085}}{{ex:ko.s0086}}
Para negar, pon 안 justo antes del verbo, como «no»: 안 가요 (no voy). El pasado y el futuro tienen su propia lección a continuación.
Errores comunes
  • 가아요 ✗ → 가요 ✓ (las vocales se funden)
  • 먹아요 ✗ → 먹어요 ✓ (ㅓ lleva 어요)
  • 하어요 ✗ → 해요 ✓ (하다 es especial)
  • Decir la forma de diccionario — 저는 가다 ✗ → 저는 가요 ✓
