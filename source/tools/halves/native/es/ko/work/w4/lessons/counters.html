En coreano las cosas se cuentan con número nativo + clasificador. El clasificador depende de lo que cuentas, como en «dos tazas de café» o «tres hojas de papel», solo que aquí es obligatorio.

El cambio del 1 al 4

Antes de un clasificador: 하나 → 한, 둘 → 두, 셋 → 세, 넷 → 네, 스물 → 스무. Todo lo demás queda igual.

Orden de las palabras

Sustantivo + número + clasificador: 맥주 (sustantivo) 두 (número) 병 (clasificador). La partícula, si la hay, va después del clasificador: 맥주 두 병을 마셨어요.

¿Te trabaste? 개 sirve para casi cualquier objeto y nadie se va a extrañar. Eso sí, nunca uses 개 para personas (명) ni para bebidas (잔).
Errores comunes
  • 두 명 para bebidas ✗ — 명 es para personas; las bebidas son 잔.
  • 세 개 사람 ✗ — el orden es sustantivo + número + clasificador: 사람 세 명.
  • 스물 살 ✗ — 스물 → 스무 antes de un clasificador: 스무 살.
