Korean counts things with native number + counter. The counter depends on what you're counting, like "two cups of coffee" or "three sheets of paper", except it's mandatory.

The 1–4 change

Before a counter: 하나 → 한, 둘 → 두, 셋 → 세, 넷 → 네, 스물 → 스무. Everything else stays the same.

Word order

Noun + number + counter: 맥주 (noun) 두 (number) 병 (counter). The particle, if any, goes after the counter: 맥주 두 병을 마셨어요.

Stuck? 개 works for almost any object and nobody will blink. Just never use 개 for people (명) or drinks (잔).
Common mistakes
  • 두 명 for drinks ✗ — 명 is people; drinks are 잔.
  • 세 개 사람 ✗ — order is noun + number + counter: 사람 세 명.
  • 스물 살 ✗ — 스물 → 스무 before a counter: 스무 살.
