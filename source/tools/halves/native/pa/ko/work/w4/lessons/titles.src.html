The 아 / 야 rule

Calling a close friend by name: a name ending in a vowel takes 야 (민수 → 민수야!), a name ending in a consonant takes 아 (지은 → 지은아!).

When unsure, 씨 after the full name is never wrong with peers. Never put 씨 after your own name, and never use 야 with anyone older than you.
