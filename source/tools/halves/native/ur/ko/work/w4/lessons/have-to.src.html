For "have to", start from the present 요-form, drop 요, and add 야 해요. In conversation people say 야 돼요 just as often; the meaning is the same.

NowHave toMeaning
가요가야 해요have to go
먹어요먹어야 해요have to eat
해요해야 해요have to do

Don't have to

This is a different pattern: 안 + 요-form without 요 + 도 돼요, literally "it's okay even if (I) don't".

{{ex:ko.s0272}}{{ex:ko.s0273}}
Without 안, the same ending gives permission: 가도 돼요? = "May I go?" You will use it in the Asking politely lesson.
Common mistakes
  • 먹야 해요 ✗ → 먹어야 해요 ✓ (start from 먹어요)
  • 하야 해요 ✗ → 해야 해요 ✓
  • 안 가야 해요 for "don't have to" ✗ → 안 가도 돼요 ✓
  • 갔어야 해요 for "had to" ✗ → 가야 했어요 ✓
