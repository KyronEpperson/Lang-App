韩语按意思拼写，说的时候再变得顺口。所以 감사합니다 听起来是 gamsahamnida，而不是 hap-ni-da。四个习惯能解释几乎所有意外。本课程的罗马音基本按实际读音写（但紧音化不写出来）。

复习：罗马音怎么读。不要按拼音读。eo、eu 各是一个元音，嘴唇不圆，跟嘴唇圆的 o、u 不同；e 和 ae 都像“也 ye”里的 e；si 接近拼音 xi，不是拼音的 si；j 接近拼音 j，ch 接近拼音 q，都不是翘舌音；g、d、b 比拼音更松，到了辅音前或词尾就写成 k、t、p；kk、tt、pp、jj、ss 是紧音，不是长音；词尾的 k、t、p 摆好口型就停住，不加元音（bap 不是“巴普”）；收音只读一次（don-i 读 do-ni，不读 don-ni）；韩语没有声调，每个音节一样重。

1 · 连音：收音移到下一个音节

下一个音节块以不发音的 ㅇ 开头时，收音就移到这个空位上。中文里也有类似的现象：“天啊”常常说成“天哪”，前一个字的 n 连到了后面。

2 · 鼻音化：ㅂ ㄷ ㄱ 在 ㄴ 和 ㅁ 前面变成鼻音

在 ㄴ 或 ㅁ 前面，ㅂ 变成 ㅁ，ㄷ 变成 ㄴ，ㄱ 变成 ㅇ（ng）。

{{ex:ko.s0022}}{{ex:ko.s0023}}{{ex:ko.s0024}}

3 · ㅎ：要么送气，要么消失

ㅎ 挨着 ㄱ ㄷ ㅂ ㅈ 时，会把它们变成送气的 ㅋ ㅌ ㅍ ㅊ。在两个元音之间，ㅎ 不发音。

{{ex:ko.s0025}}{{ex:ko.s0026}}{{ex:ko.s0027}}

4 · ㄴ 遇到 ㄹ：都变成 ㄹ

ㄴ 和 ㄹ 挨在一起时，读成一个长长的 l。罗马音写作 ll（yeollak、seollal）：舌尖顶住上齿龈不放，不要卷舌。

{{ex:ko.s0028}}{{ex:ko.s0029}}
还有一个你会听到的：在 ㄱ ㄷ ㅂ 后面，下一个辅音会变成紧音，所以 학교 听起来像 학꾜。罗马音不标这一点。想练耳朵，就回到课程里反复听这些例句，再做练习，并在复习里过一遍卡片。
常见错误
  • 一个音节块一个音节块地读：gam-sa-hap-ni-da ✗ → gamsahamnida ✓
  • 在 ㅇ 前面停顿：han-guk-eo ✗ → hangugeo ✓
  • 把 좋아요 的 ㅎ 读出来：jo-ha-yo ✗ → joayo ✓
  • 照读音拼写：조아요 ✗ → 좋아요 ✓（拼写永远不变）
