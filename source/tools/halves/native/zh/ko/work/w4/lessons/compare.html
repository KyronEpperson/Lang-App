韩语形容词比较时从不变形，只要加几个小词：보다（比）、더（更）、덜（没那么）和 제일（最），跟中文的“比”“更”“最”很像。

보다 = 比

보다 贴在被比较的那个东西后面。语序跟中文“A比B便宜”一样：A、B、形容词。唯一的区别是：中文的“比”在 B 前面，보다 在 B 后面。더 可加可不加，但很常用。

语序可以调换

因为 보다 已经标出了“比”的对象，两个名词可以换位置。中文的“比”不能这样挪。

{{ex:ko.s0245}}

더 = 更，덜 = 没那么

它们紧贴在形容词前面，也可以单独跟动词连用。

这里的 보다 是贴在名词上的助词，只是长得像动词 보다（看）。动词会变形（봐요），助词永远不变。
常见错误
  • 보다 放错名词：버스보다 택시가 싸요 的意思是出租车更便宜
  • 더 제일 맛있어요 ✗ → 제일 맛있어요 ✓（二选一）
  • 택시 보다 ✗ → 택시보다 ✓（不空格，它是助词）
  • 더 放在形容词后面：싸요 더 ✗ → 더 싸요 ✓
