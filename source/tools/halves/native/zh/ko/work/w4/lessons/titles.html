韩语很少说“你”，对年长的人几乎从不直呼名字。称呼别人要用职位、身份或亲属称呼。

说法对谁例子
이름 + 씨同辈、同事，礼貌的默认叫法민수 씨, 지은 씨
직함 + 님有职位、身份的人，顾客선생님, 사장님（老板）, 고객님
오빠 / 형年长的男性（女生叫 / 男生叫）민수 오빠, 민수 형
언니 / 누나年长的女性（女生叫 / 男生叫）지은 언니, 지은 누나
光叫名字 + 아/야只用于好朋友和比你小的人민수야!, 지은아!

아 / 야 的规则

直接叫好朋友的名字时：名字以元音结尾加 야（민수 → 민수야!），以辅音结尾加 아（지은 → 지은아!）。

拿不准时，对同辈在全名后加 씨 绝不会错。注意三点：선생님 是“老师”，不是“先生”；오빠 / 형、언니 / 누나 按说话人的性别来选，跟中文“哥哥”“姐姐”不同；自己的名字后面绝不加 씨，对比你大的人绝不用 야。
