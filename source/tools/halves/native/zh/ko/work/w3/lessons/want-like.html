这是任何语言里都最有用的两个句型。“想”接动词，“喜欢”接名词。意思跟中文一一对应，只是位置不同。

想：词干 + 고 싶어요

中文的“想”放在动词前面（想去），韩语放在动词后面：去掉 다，加 고 싶어요。不用管元音规则。

喜欢：名词 + 을/를 좋아해요

좋아해요 是动词（“喜欢”），喜欢的东西是宾语，用 을/를，就像中文“喜欢咖啡”里咖啡是宾语。它的近亲 좋아요（“好”）是形容词，前面用 이/가，就像“咖啡很好”。中文母语者最常见的错误就是把这两个混起来：喜欢的东西后面误用 이/가。

{{ex:ko.s0173}}{{ex:ko.s0174}}{{ex:ko.s0175}}{{ex:ko.s0176}}
想要一个东西时，韩国人一般说出动作：“我想要咖啡”说成 커피 마시고 싶어요（想喝咖啡），或者就像中文“我要咖啡”那样直接说 커피 주세요。
常见错误
  • 가다고 싶어요 ✗ → 가고 싶어요 ✓（先去掉 다）
  • 가요 싶어요 ✗ → 가고 싶어요 ✓
  • 커피가 좋아해요 ✗ → 커피를 좋아해요 ✓
  • 커피를 좋아요 ✗ → 커피가 좋아요 ✓
