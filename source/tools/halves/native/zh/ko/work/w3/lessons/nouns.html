名词是人、地方、事物的名称：친구（朋友）、집（家）、커피（咖啡）。这一点跟中文一样：没有冠词，名词本身也从不变形。复数可加可不加：一个词既能指一个，也能指很多；들 表示“不止一个”，跟“们”很像，也主要用在人身上。

这、那、那边

中文只分“这”和“那”，韩语分三个：이（这，离我近）、그（那，离你近）、저（那边，离我们俩都远）。都放在名词前面。

名词 + 名词 = 谁的

所有者放在前面就行。表示所属的 의 相当于“的”，但常常省掉，就像中文说“我妈妈”不说“我的妈妈”。“我的”是 제（礼貌）或 내（半语）。

“是……”的说法

名词有收音，后面接 이에요；以元音结尾，接 예요。相当于“A 是 B”的“是”。“不是”用 이/가 아니에요。

{{ex:ko.s0038}}{{ex:ko.s0039}}{{ex:ko.s0040}}{{ex:ko.s0041}}

은/는：说到的话题

句子要说的那个东西就是话题。中文靠位置标出话题（“这本书嘛，我看过了”），韩语在后面加话题助词：有收音加 은，以元音结尾加 는，意思像“说到……”。然后再说它是什么。注意：은/는 标的是话题，不等于主语。

很多名词是汉字词，由能反复使用的“字”组成，这正是你的优势。학 就是“学”：학교（学校）、학생（学生）。학원 在韩语里指补习班。认出一个字，新词就好记多了。
常见错误
  • 什么都加 들（就像不说“三个苹果们”）—— 사과들 세 개 ✗ → 사과 세 개 ✓
  • 이에요 / 예요 混用 —— 선생님예요 ✗ → 선생님이에요 ✓ · 가수이에요 ✗ → 가수예요 ✓
  • 元音后面用 은 —— 저은 학생이에요 ✗ → 저는 학생이에요 ✓
  • 想找一个表示“the”的词：这是英语母语者的问题，韩语跟中文一样，没有冠词。
