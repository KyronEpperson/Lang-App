中文的基本语序是主语—动词—宾语：“我吃饭”。韩语是主语—宾语—动词：“我饭吃”。其他成分可以挪动，但动词一定在句子最后。好消息是，中文本来就把时间、地点放在动词前面（“我昨天在家学习”），所以真正要挪的只有宾语。你其实已经有现成的钩子：“我把饭吃了”里，“把”就把宾语提到了动词前面。韩语天天这么说，而且不用“把”，而是在宾语后面加宾格助词 을/를。

宾格助词 을/를

被吃、被喝、被看、被学、被买的东西就是宾语：有收音加 을，以元音结尾加 를。

{{ex:ko.s0111}}{{ex:ko.s0112}}{{ex:ko.s0113}}

形容词用 이/가，不用 을/를

좋아요、커요 描述的是名词本身，没有谁对它做什么，所以没有宾语。就像中文“包很大”，“包”是主语。

{{ex:ko.s0072}}{{ex:ko.s0073}}

能省就省

跟中文一样，只要上下文清楚，主语就省掉；随便说话时 을/를 也常省掉。真实对话里多半只剩宾语和动词，就像中文说“吃了吗？”

{{ex:ko.s0114}}{{ex:ko.s0115}}{{ex:ko.s0116}}

疑问句

语序不变。在 요体里，疑问句就是同一句话，语调上扬，不用加“吗”。疑问词跟中文一样放在答案的位置：뭐（什么）、어디（哪儿）、언제（什么时候）、누구（谁）、왜（为什么）、어떻게（怎么）。

拿不准要不要省 을/를，就留着。助词齐全的句子永远是对的，只是听起来稍微正式一点。

  • 按中文语序说 —— 저는 먹어요 밥을 ✗ → 저는 밥을 먹어요 ✓
  • 形式用错 —— 밥를 먹어요 ✗ → 밥을 먹어요 ✓ · 커피을 ✗ → 커피를 ✓
  • 形容词前用 을/를 —— 가방을 커요 ✗ → 가방이 커요 ✓
