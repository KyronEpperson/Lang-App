韩语数东西用固有词数字 + 量词。量词随所数的东西变化，跟中文的“两杯咖啡”“三张纸”一样，也是非用不可的。真正不同的是语序（见下文）。

量词数什么例子
개东西（通用），≈ 个사과 두 개
명 / 분人 / 人（礼貌），≈ 名 / 位세 명, 세 분
잔杯커피 한 잔
병瓶맥주 두 병
마리动物，≈ 只、头강아지 한 마리
권书，≈ 本책 세 권
장扁平的东西、票，≈ 张표 두 장
살岁数，≈ 岁스물다섯 살
시간小时（时长）두 시간
번次数，≈ 次세 번

1–4 的变化

在量词前面：하나 → 한，둘 → 두，셋 → 세，넷 → 네，스물 → 스무。其余的数字不变。中文在量词前把“二”换成“两”，道理差不多。

语序

名词 + 数字 + 量词：맥주（名词）두（数字）병（量词）。中文正好反过来，说“两瓶啤酒”。如果有助词，放在量词后面：맥주 두 병을 마셨어요。

拿不准？개 几乎能数任何东西，就像中文的“个”，没人会在意。只是数人绝不能用 개（要用 명）。饮料的标准量词是 잔，不过在咖啡店点单时也常说 개。
常见错误
  • 饮料说 두 명 ✗：명 是数人的，饮料用 잔。
  • 세 개 사람 ✗：照中文“三个人”的顺序说就错了，要说“名词 + 数字 + 量词”：사람 세 명。
  • 스물 살 ✗：스물 在量词前面变成 스무：스무 살。
