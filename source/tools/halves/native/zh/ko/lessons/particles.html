에 和 에서 都接在地点后面，中文常常都说成“在”。区别在动词。에 跟“去、来、在某处”搭配，也用在时间后面；에서 跟“在某处做事”搭配，也表示“从”。

에：去哪儿

去处 + 에，后面接 가요（去）、와요（来）。中文“去学校”不用“在”，韩语照样要加 에。

에：东西在哪儿，什么时候

位置 + 에，后面接 있어요 / 없어요；时间词 + 에：주말에（周末）、아침에（早上）。

{{ex:ko.s0056}}{{ex:ko.s0123}}{{ex:ko.s0124}}

에서：在哪儿做事，以及“从”

在某个地方做动作（吃饭、学习、休息、工作），地点 + 에서。跟 왔어요 一起时表示“从”。

{{ex:ko.s0125}}{{ex:ko.s0126}}{{ex:ko.s0299}}

话题和主语，简单说

은/는 是话题助词，先定下要说的范围（“说到我……”），有的教材叫补助词或添意助词。이/가 是主格助词，指出具体是哪一个，特别是新信息，或者“谁？”“什么？”的答案。

也도저도（我也是）—— 后面会学
快速判断：先看动词。가요、와요、있어요、없어요 → 에。在那儿主动做的事（먹어요、공부해요、쉬어요）→ 에서。再加一个中文的判断法：“在家”后面是“有 / 住 / 待着”→ 에；“在家”后面是一个动作（“在家休息”）→ 에서；“去 / 来 + 地点”→ 에；“从”→ 에서。
常见错误
  • 去处用 에서 —— 집에서 가요 ✗ → 집에 가요 ✓
  • 动作用 에（因为中文都说“在”）—— 카페에 공부해요 ✗ → 카페에서 공부해요 ✓
  • 있어요 用 에서 —— 집에서 있어요 ✗ → 집에 있어요 ✓
  • 把助词放在名词前面（像“在家”的“在”那样）—— 에 집 ✗ → 집에 ✓
