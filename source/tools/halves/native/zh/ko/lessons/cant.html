“不”你已经会用 안 说了。“不能”在韩语里是另一个词：못，相当于“不能”“不会”“……不了”。“能”用句型 -(으)ㄹ 수 있어요，否定是 -(으)ㄹ 수 없어요。再加上两种“不知道”的说法，就能礼貌地拒绝任何事。

안 = 不（不想），못 = 不能

两个都紧贴在动词前面。按意思选：是自己的选择（안），还是有原因做不到（못）。中文的“没吃”也有这两种意思：不想吃，或者没能吃。

하다 动词要拆开，跟 안 一样

못 放在名词和 해요 中间，不说 못 공부해요。

{{ex:ko.s0296}}{{ex:ko.s0257}}

能：-(으)ㄹ 수 있어요 / 없어요

元音后面用 词干 + ㄹ 수 있어요，辅音后面用 을 수 있어요。换成 없어요 就是“不能”。中文的“能”和“会”都可以用它来说。

{{ex:ko.s0258}}{{ex:ko.s0259}}{{ex:ko.s0260}}{{ex:ko.s0261}}

몰라요 和 모르겠어요

몰라요 = 不知道（某个事实）。모르겠어요 = 不太清楚 / 没明白，语气更委婉，被人问到时更常用。肯定的说法是 알아요。“不知道”是一个单独的动词，不是 안 + 알아요。

{{ex:ko.s0262}}{{ex:ko.s0263}}{{ex:ko.s0264}}
被问 매운 거 먹을 수 있어요?（你能吃辣吗？）几乎是必经的一关。回答 네, 잘 먹어요 会让人刮目相看；조금요 是老实的回答。另外，한국어 잘 못해요（我韩语说得不好）里的 못해요 表示“不擅长”，要写成一个词。
常见错误
  • 하다 动词把 못 放在名词前面：못 공부해요 ✗ → 공부 못 해요 ✓
  • 做不到却用 안：辣得受不了还说 매운 거 안 먹어요 ✗ → 매운 거 못 먹어요 ✓
  • 辅音后面漏了 을：먹 수 있어요 ✗ → 먹을 수 있어요 ✓
  • 没听懂时生硬地说 몰라요：몰라요 ✗ → 잘 모르겠어요 ✓
