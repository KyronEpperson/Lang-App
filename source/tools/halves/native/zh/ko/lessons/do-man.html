도 是“也”，만 是“只”。注意位置：中文的“也”“只”放在动词前面（我也去、只喝咖啡），韩语的 도、만 是助词，跟别的助词一样贴在名词后面（저도 = 我也，커피만 = 只……咖啡）。要记的规则只有一条：它们代替 은/는、이/가、을/를，但接在 에 和 에서 后面。

도 = 也

哪个东西“也”是这样，就把 도 贴在哪个名词后面。

도 代替 은/는、이/가、을/를

原来的助词去掉，换成 도。不能叠在一起用。

만 = 只

만 用法一样：代替 은/는、이/가、을/를。이것 是 이거（这个）的完整形式。

在 에 和 에서 后面叠用

에 和 에서 有自己的意思（到、在、从），所以保留，도 / 만 放在它们后面。

{{ex:ko.s0153}}{{ex:ko.s0154}}{{ex:ko.s0155}}
도 + 否定 = “也不”：저도 안 가요 = 我也不去。저도요（我也是）是加入任何对话最简单的一句。
常见错误
  • 도 叠在 은/는 后面 —— 저는도 ✗ → 저도 ✓
  • 만 叠在 을/를 后面 —— 커피를만 마셔요 ✗ → 커피만 마셔요 ✓
  • 漏掉 에 —— 집도 있어요（= 我也有房子）✗ → 집에도 있어요 ✓
  • 顺序错 —— 학교도에서 ✗ → 학교에서도 ✓
