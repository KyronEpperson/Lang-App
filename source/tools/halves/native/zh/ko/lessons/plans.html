三个词尾就能应付所有邀请，都接在动词词干后面。

词尾语气例子
-(으)ㄹ까요?“……好吗？”“……吧？”：委婉的提议커피 마실까요? / 카페 갈까?
-(으)ㄹ래요?“要不要……？”：问对方的意愿같이 갈래요? / 영화 볼래?
-자“咱们……吧”：半语，口气肯定놀자! / 밥 먹자

元音词干后面加 ㄹ（가 → 갈까요），辅音词干后面加 을（먹 → 먹을까요）。

韩国人约见面说“地铁站 + 出口号码”，不说地址：강남역 11번 출구。中国的大城市也常这样约。记住你常去的站有哪些出口。
常见错误
  • 对长辈说 볼래요：要说 보실래요 或 볼까요?
  • 报地址：韩国人说站名 + 出口：강남역 11번 출구。
  • 只用 네 答应：加上 좋아요 或 콜，听起来才热情。
