基本形以 다 结尾：가다（去）、먹다（吃）、하다（做）。去掉 다 得到词干，再加上礼貌的词尾。这一个形式就包括了“我去”“我正在去”和“你去吗？”。

按最后一个元音选词尾

这是中文没有的规则，叫元音和谐。看词干的最后一个元音：ㅏ、ㅗ 是阳性元音，其他是阴性元音。

最后一个元音加例子
ㅏ 或 ㅗ아요가다 → 가요 · 보다 → 봐요
其他元音어요먹다 → 먹어요 · 마시다 → 마셔요
하다 动词해요하다 → 해요 · 공부하다 → 공부해요

元音合并

词干以元音结尾时，两个元音合成一个：가 + 아요 = 가요，오 + 아요 = 와요，마시 + 어요 = 마셔요。

一个形式，多种用法

陈述、疑问、“正在”都用同一个词。中文问句要加“吗”，韩语只要语调上扬。

{{ex:ko.s0083}}{{ex:ko.s0084}}{{ex:ko.s0085}}{{ex:ko.s0086}}
表示“不”，把 안 紧贴在动词前面：안 가요（不去）。过去时和将来时在后面两课。
常见错误
  • 가아요 ✗ → 가요 ✓（元音要合并）
  • 먹아요 ✗ → 먹어요 ✓（ㅓ 接 어요）
  • 하어요 ✗ → 해요 ✓（하다 比较特殊）
  • 直接说基本形 —— 저는 가다 ✗ → 저는 가요 ✓
