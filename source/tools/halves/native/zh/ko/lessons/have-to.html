说“得……”“必须……”，从现在时的 요体出发，去掉 요，加上 야 해요。口语里说 야 돼요 的也一样多，意思相同。

现在得……意思
가요가야 해요得去
먹어요먹어야 해요得吃
해요해야 해요得做

不用……

这是另一个句型：안 + 去掉 요 的 요体 + 도 돼요，字面意思是“不……也行”，正好就是中文的“不用”。

{{ex:ko.s0272}}{{ex:ko.s0273}}
不加 안，同一个词尾就表示允许，相当于“可以……吗”：가도 돼요? = “我可以走吗？” 第 32 课“礼貌地请求”会用到它。
常见错误
  • 먹야 해요 ✗ → 먹어야 해요 ✓（从 먹어요 出发）
  • 하야 해요 ✗ → 해야 해요 ✓
  • “不用去”说成 안 가야 해요 ✗ → 안 가도 돼요 ✓
  • “当时得去”说成 갔어야 해요 ✗ → 가야 했어요 ✓
