名词、动词、助词你都有了。初学阶段几乎每句话都是下面四种句型之一，而且动词永远在最后。

1 · A 是 B

名词 + 이에요 / 예요。像“我是学生”。

{{ex:ko.s0059}}

2 · A 怎么样

名词 + 이/가 + 形容词。像“咖啡很好喝”，不用“是”。

{{ex:ko.s0156}}

3 · 对 A 做某事

名词 + 을/를 + 动词。像“喝咖啡”，但顺序是“咖啡喝”。

{{ex:ko.s0112}}

4 · 去某处 / 在某处 / 在某处做事

地点 + 에，接 가요、와요、있어요（去、来、在）；在那儿做动作，地点 + 에서。像“去咖啡馆”和“在咖啡馆学习”。

{{ex:ko.s0157}}{{ex:ko.s0126}}

一块一块加长

从动词开始，往前面加。一般的语序是：谁 · 什么时候 · 跟谁 · 在哪儿 · 什么 · 动词。这跟中文“我今天和朋友在咖啡馆喝咖啡”几乎一样，只有宾语和动词换了位置。

{{ex:ko.s0158}}{{ex:ko.s0112}}{{ex:ko.s0159}}{{ex:ko.s0160}}

替换零件

框架不变，只换一个词。一句话就这样变成五十句。

{{ex:ko.s0161}}{{ex:ko.s0162}}{{ex:ko.s0163}}{{ex:ko.s0164}}
说到一半卡住了？先把会的名词说出来，最后补上动词。反正韩国人听话也是在等最后的动词。
常见错误
  • 按中文语序说 —— 저는 마셔요 커피를 ✗ → 저는 커피를 마셔요 ✓
  • 形容词前用 을/를 —— 커피를 맛있어요 ✗ → 커피가 맛있어요 ✓
  • 在某处做事用 에（因为中文都说“在”）—— 카페에 공부해요 ✗ → 카페에서 공부해요 ✓
