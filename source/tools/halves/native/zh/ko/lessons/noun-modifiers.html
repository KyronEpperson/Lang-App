到现在为止，形容词都放在句尾：가방이 커요（包很大）。要说“大的包”，形容词就要移到名词前面，并换一个词尾。这跟中文的“……的”一样：“大的包”“好吃的菜”，修饰语都在名词前面。这个词尾叫定语词尾（教材里也叫冠形词尾）。

元音词干 + ㄴ，辅音词干 + 은

去掉 다。词干以元音结尾，就在下面加 ㄴ；以辅音结尾，就加 은。

맛있다、재미있다 这类词改用 는。

很多表示天气和味道的词以 ㅂ 结尾。ㅂ 先变成 우，再加 ㄴ。

用在句子里

形容词和它修饰的名词是一个整体，助词加在名词后面。

动词也能用 는 修饰名词：제가 좋아하는 음식 = “我喜欢的菜”。跟中文完全一样，不需要英语那样的 that / which / who，整个修饰语直接放在名词前面：中文用“的”，韩语用词尾。
常见错误
  • 크은 가방 ✗ → 큰 가방 ✓
  • 맛있은 음식 ✗ → 맛있는 음식 ✓
  • 맵은 음식 ✗ → 매운 음식 ✓
  • 照英语的语序：가방 큰 ✗ → 큰 가방 ✓（中文“大的包”本来就是这个顺序）
