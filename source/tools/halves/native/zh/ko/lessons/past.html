最难的部分你已经会了。拿现在时的 요体，去掉 요，加上 ㅆ어요：가요 → 갔어요，먹어요 → 먹었어요，해요 → 했어요。

해요했어요做了

时间词放在前面

어제（昨天）、아까（刚才）、지난주（上周）放在句首交代时间，跟中文一样。中文“没去”“没吃”的“没”，韩语是 안 + 过去时，跟“没有（东西）”无关。

{{ex:ko.s0095}}{{ex:ko.s0096}}{{ex:ko.s0097}}
“吃了”“吃过了”“已经吃了”都是 먹었어요。但“了”不等于过去时：“了”表示完成或变化，韩语看的是时间。过去的事即使中文不加“了”（“我以前是学生”），韩语也要用过去时；“下雨了”说的是现在下着雨，韩语反而用现在时。
常见错误
  • 가었어요 ✗ → 갔어요 ✓（从 가요 变，不从 가다 变）
  • 하었어요 ✗ → 했어요 ✓
  • 학생였어요 ✗ → 학생이었어요 ✓（有收音 → 이었어요）
  • 갔어요 안 ✗ → 안 갔어요 ✓
