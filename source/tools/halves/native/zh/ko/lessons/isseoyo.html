中文有三个常用的词：“是”“有”“在”。韩语只用两个：이에요/예요 相当于“是”，说某物是什么；있어요 一个词就包括了“有”和“在”：有什么东西、东西在哪儿、你拥有什么。它的反面是 없어요，相当于“没有”“不在”。两个短短的动词，你需要的东西已经能问一半了。

有，没有

있어요 = 有 / 有……吗？；없어요 = 没有。问的时候语调上扬（不用加“吗”），回答时用同一个动词，就像中文“有吗？——有。”

主格助词 이/가

存在的那个东西后面加主格助词：有收音加 이，以元音结尾加 가。

拥有：“我有……”

韩语的说法是“说到我，有 X”。拥有的人用话题助词 은/는，东西用 이/가。这跟中文的话题句很像：“我嘛，有一只猫”。

在哪儿：地点 + 에

中文说“猫在家”，“在”放在地点前面；韩语在地点后面加 에，再用 있어요 或 없어요。注意：“在”不是另一个动词，就是 있어요。

이에요 还是 있어요？

中文用“是”的句子（A 是 B），用 이에요/예요。中文用“有”或“在”的句子，用 있어요。

中文韩语原因
我是学生학생이에요我 = 学生（是）
我在学校학교에 있어요位置（在）
这里是学校여기는 학교예요这里 = 学校（是）
这里有一所学校여기에 학교가 있어요存在（有）
口语里，短问句常省掉 이/가：问“有空吗？”，大家实际上说 시간 있어요? 不过看书和说长句时还是需要 이/가。
常见错误
  • 说“在某处”要用 있어요，完整的说法是 저는 학교에 있어요 ✓（口语里也会听到 지금 학교예요，“我现在在学校”）
  • 把“有”说成“是”—— 저는 고양이예요 ✗（= 我是一只猫）→ 저는 고양이가 있어요 ✓
  • 이/가 用错 —— 시간가 있어요 ✗ → 시간이 있어요 ✓
  • 漏掉 에 —— 고양이가 집 있어요 ✗ → 고양이가 집에 있어요 ✓
