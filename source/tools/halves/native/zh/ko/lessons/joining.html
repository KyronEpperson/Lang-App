说短句没问题，但把句子连起来，听起来才流利。下面每个词尾都用来替换前一个句子的 요 词尾。

-고 = 和、然后

词干 + 고。用于并列两个事实（又……又……），或先后两个动作（……然后……）。

{{ex:ko.s0214}}{{ex:ko.s0215}}

-지만 = 但是

词干 + 지만，相当于“虽然……但是……”。

{{ex:ko.s0216}}{{ex:ko.s0217}}

-아/어서 = 因为……所以……

先变成 요体，再把 요 换成 서。跟中文一样，原因在前。不同的是，中文可以把原因放到后面（“我没去，因为很忙”），서 不行。

{{ex:ko.s0218}}{{ex:ko.s0219}}

-아/어서 = 去（来）了以后……

跟 가다、오다 连用，把同一趟的两步连起来：先去，再在那儿做事。

{{ex:ko.s0220}}{{ex:ko.s0221}}

时态放在最后一个动词上

-아/어서 从来不用过去时，由最后的动词表示时间，就像“因为忙，所以没去”里只有后半句说的是过去。

{{ex:ko.s0222}}
两个完整的句子之间，改用独立的连接词：그리고（而且、然后）、하지만 或 그런데（但是）、그래서（所以）。下一课就用它们讲故事。
常见错误
  • 바빴어서 ✗ → 바빠서 ✓（서 前面不用过去时）
  • 싸요고 ✗ → 싸고 ✓（接在词干上）
  • 비싸요지만 ✗ → 비싸지만 ✓
  • 用混了：비싸서 맛있어요 的意思是“因为贵，所以好吃”
