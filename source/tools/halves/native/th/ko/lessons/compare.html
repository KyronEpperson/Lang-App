กริยาบอกลักษณะในภาษาเกาหลีไม่เปลี่ยนรูปเวลาเปรียบเทียบ แค่เติมคำเล็ก ๆ ได้แก่ 보다 (กว่า) 더 (มากกว่า) 덜 (น้อยกว่า) และ 제일 (ที่สุด) เหมือนภาษาไทยที่เติม กว่า หรือ ที่สุด

보다 = กว่า

ต่อ 보다 ท้ายสิ่งที่นำมาเทียบ คือสิ่งที่อยู่หลัง กว่า ในภาษาไทย: รถเมล์ถูกกว่าแท็กซี่ → 보다 ต่อท้ายแท็กซี่ จะใส่ 더 หรือไม่ก็ได้ แต่นิยมใส่

{{ex:ko.s0243}}{{ex:ko.s0244}}

สลับลำดับได้

เพราะ 보다 บอกไว้แล้วว่าอะไรคือสิ่งที่นำมาเทียบ คำนามทั้งสองจึงสลับที่กันได้

{{ex:ko.s0245}}

더 = มากกว่า 덜 = น้อยกว่า

วางไว้หน้ากริยาบอกลักษณะทันที หรือใช้เดี่ยว ๆ กับคำกริยา

{{ex:ko.s0246}}{{ex:ko.s0247}}{{ex:ko.s0248}}

제일 = ที่สุด

가장 มีความหมายเหมือนกันแต่ฟังเป็นทางการขึ้นเล็กน้อย ระวังลำดับ: ภาษาไทยวาง ที่สุด ไว้หลังคำ แต่ 제일 อยู่หน้าคำ

{{ex:ko.s0249}}{{ex:ko.s0250}}

ถามให้เลือก

{{ex:ko.s0251}}{{ex:ko.s0252}}
보다 ตรงนี้เป็นคำช่วยที่ติดกับคำนาม แค่หน้าตาเหมือนคำกริยา 보다 (ดู) คำกริยาจะผันรูป (봐요) แต่คำช่วยไม่เปลี่ยนเลย
ข้อผิดพลาดที่พบบ่อย
  • ใส่ 보다 ผิดคำนาม: 버스보다 택시가 싸요 แปลว่าแท็กซี่ถูกกว่า
  • 더 제일 맛있어요 ✗ → 제일 맛있어요 ✓ (เลือกอย่างใดอย่างหนึ่ง)
  • 택시 보다 ✗ → 택시보다 ✓ (ไม่เว้นวรรค เพราะเป็นคำช่วย)
  • วาง 더 หลังคำคุณศัพท์ตามลำดับไทย: 싸요 더 ✗ → 더 싸요 ✓
