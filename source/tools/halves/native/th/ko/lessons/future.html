거예요 ออกเสียง k แบบเกร็ง คล้าย kkeoyeyo (เสียง ก ไม่ใช่ ค) ถ้าเป็นเรื่องที่กำหนดไว้แล้วและใกล้จะถึง ใช้รูปปัจจุบันธรรมดาก็ได้: 내일 가요 (พรุ่งนี้ไปครับ/ค่ะ) เหมือนภาษาไทยที่พูดว่า พรุ่งนี้ไป โดยไม่ต้องมี จะ
ข้อผิดพลาดที่พบบ่อย
  • 가을 거예요 ✗ → 갈 거예요 ✓ (ก้านลงท้ายด้วยสระ → ㄹ)
  • 먹ㄹ 거예요 ✗ → 먹을 거예요 ✓ (ก้านมีตัวสะกด → 을)
  • 갈 거 안 예요 ✗ → 안 갈 거예요 ✓
  • 갈거에요 ✗ → 갈 거예요 ✓ (สะกดว่า 예요)
