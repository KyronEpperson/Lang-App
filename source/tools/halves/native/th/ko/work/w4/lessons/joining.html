ประโยคสั้น ๆ ก็ใช้ได้ แต่การเชื่อมประโยคทำให้ฟังคล่องขึ้นมาก ส่วนลงท้ายแต่ละตัวต่อไปนี้ใช้แทนส่วนลงท้าย 요 ของประโยคแรก

-고 = และ แล้วก็

ก้านกริยา + 고 ใช้กับข้อเท็จจริงสองอย่าง หรือการกระทำสองอย่างที่ทำต่อกัน

-지만 = แต่

ก้านกริยา + 지만

{{ex:ko.s0216}}{{ex:ko.s0217}}

-아/어서 = ก็เลย

ใช้รูป 요 แล้วเปลี่ยน 요 เป็น 서 เหตุผลมาก่อนเสมอ เหมือน ยุ่งเลยไม่ไป ต่างจาก เพราะ ที่วางเหตุผลไว้ข้างหลัง

{{ex:ko.s0218}}{{ex:ko.s0219}}

-아/어서 = ไปแล้วก็…

เมื่อใช้กับ 가다 และ 오다 จะเชื่อมสองขั้นตอนของการไปครั้งเดียวกัน

{{ex:ko.s0220}}{{ex:ko.s0221}}

รูปอดีตอยู่ที่คำกริยาตัวสุดท้าย

-아/어서 ไม่ใช้รูปอดีตเลย คำกริยาตัวสุดท้ายเป็นตัวบอกเวลา เทียบ ยุ่งเลยไม่ไป กับ ยุ่งเลยไม่ได้ไป ส่วนแรกเหมือนกัน ต่างกันแค่ท้ายประโยค

{{ex:ko.s0222}}
ระหว่างสองประโยคเต็ม ให้ใช้คำเชื่อมที่แยกเป็นคำแทน: 그리고 (แล้วก็) 하지만 หรือ 그런데 (แต่) 그래서 (ก็เลย) บทต่อไปจะใช้คำเหล่านี้เล่าเรื่อง
ข้อผิดพลาดที่พบบ่อย
  • 바빴어서 ✗ → 바빠서 ✓ (ไม่มีรูปอดีตหน้า 서)
  • 싸요고 ✗ → 싸고 ✓ (ต่อท้ายก้านกริยา)
  • 비싸요지만 ✗ → 비싸지만 ✓
  • ใช้สลับกัน: 비싸서 맛있어요 แปลว่า “อร่อยเพราะแพง”
