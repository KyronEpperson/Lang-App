ภาษาเกาหลีแทบไม่ใช้คำว่า คุณ และแทบไม่เรียกชื่อเฉย ๆ กับคนที่อายุมากกว่า แต่เรียกด้วยตำแหน่งหรือคำเรียกความสัมพันธ์ คล้ายที่คนไทยเรียก พี่ น้อง หรือ คุณ + ชื่อ ข้อต่างคือภาษาไทยใช้ พี่ คำเดียว แต่ภาษาเกาหลีเลือกคำตามเพศของผู้พูด

ใช้กับใครตัวอย่าง
이름 + 씨คนระดับเดียวกัน เพื่อนร่วมงาน คำเรียกสุภาพพื้นฐาน (เหมือน คุณ + ชื่อ แต่ 씨 อยู่หลังชื่อ)민수 씨, 지은 씨
직함 + 님คนที่มีตำแหน่งหรือบทบาท ลูกค้า선생님, 사장님 (เจ้าของร้าน / ประธานบริษัท), 고객님
오빠 / 형ผู้ชายที่อายุมากกว่า (ถ้าผู้พูดเป็นผู้หญิง / ผู้ชาย)민수 오빠, 민수 형
언니 / 누나ผู้หญิงที่อายุมากกว่า (ถ้าผู้พูดเป็นผู้หญิง / ผู้ชาย)지은 언니, 지은 누나
ชื่อเฉย ๆ + 아/야เพื่อนสนิทและคนที่อายุน้อยกว่าเท่านั้น민수야!, 지은아!

กฎ 아 / 야

เวลาเรียกชื่อเพื่อนสนิท ชื่อที่ลงท้ายด้วยสระ ใช้ 야 (민수 → 민수야!) ชื่อที่ลงท้ายด้วยตัวสะกด ใช้ 아 (지은 → 지은아!)

ถ้าไม่แน่ใจ ใช้ชื่อเต็ม + 씨 กับคนระดับเดียวกันไม่มีวันผิด ห้ามใส่ 씨 หลังชื่อตัวเอง และห้ามใช้ 야 กับคนที่อายุมากกว่า
