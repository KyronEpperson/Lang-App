รูปพจนานุกรมลงท้ายด้วย 다: 가다 (ไป) 먹다 (กิน) 하다 (ทำ) ตัด 다 ออกจะได้ก้านกริยา แล้วเติมส่วนลงท้ายแบบสุภาพ รูปเดียวนี้ใช้ได้ทั้ง “ไป” “กำลังไป” และ “ไปไหม” เหมือนภาษาไทยที่กริยาไม่เปลี่ยนรูป สิ่งใหม่ในบทนี้มีแค่การเลือกส่วนลงท้ายตามสระ

เลือกส่วนลงท้ายตามสระตัวสุดท้าย

ดูสระตัวสุดท้ายของก้านกริยา:

สระตัวสุดท้ายเติมตัวอย่าง
ㅏ หรือ ㅗ아요가다 → 가요 · 보다 → 봐요
สระอื่น ๆ어요먹다 → 먹어요 · 마시다 → 마셔요
กริยา 하다해요하다 → 해요 · 공부하다 → 공부해요

สระรวมกัน

เมื่อก้านกริยาลงท้ายด้วยสระ สระสองตัวจะรวมเป็นหนึ่ง: 가 + 아요 = 가요 · 오 + 아요 = 와요 · 마시 + 어요 = 마셔요

ข้อผิดพลาดที่พบบ่อย
  • 가아요 ✗ → 가요 ✓ (สระรวมกัน)
  • 먹아요 ✗ → 먹어요 ✓ (ㅓ ใช้ 어요)
  • 하어요 ✗ → 해요 ✓ (하다 เป็นคำพิเศษ)
  • พูดรูปพจนานุกรม — 저는 가다 ✗ → 저는 가요 ✓
