ทั้ง 에 และ 에서 ต่อท้ายสถานที่ และภาษาไทยมักแปลทั้งสองคำว่า “ที่” ตัวตัดสินคือคำกริยา 에 ใช้กับการไป การมา และการอยู่ที่ไหนสักแห่ง รวมถึงเวลา 에서 ใช้กับการทำกิจกรรมที่สถานที่นั้น และใช้แปลว่า “จาก” อีกเรื่องที่ต่างกันคือ ภาษาไทยวางคำบุพบทไว้หน้าคำนาม (ที่บ้าน) แต่ภาษาเกาหลีวางคำช่วยไว้หลังคำนาม

에: ที่ที่ไป

จุดหมาย + 에 กับ 가요 (ไป) และ 와요 (มา) ภาษาไทยพูดว่า ไปโรงเรียน โดยไม่มีคำบุพบท แต่ภาษาเกาหลีใส่ 에

에: ที่ที่สิ่งของอยู่ และเวลา

สถานที่ + 에 กับ 있어요 / 없어요 และคำบอกเวลา + 에: 주말에 (ช่วงสุดสัปดาห์) 아침에 (ตอนเช้า)

ทดสอบง่าย ๆ คือดูที่คำกริยา 가요 와요 있어요 없어요 → 에 ถ้าเป็นสิ่งที่ลงมือทำที่นั่น (먹어요 공부해요 쉬어요) → 에서 ภาษาไทยใช้ ที่ ทั้งสองแบบ: อยู่ที่บ้าน ใช้ 에 แต่ กินข้าวที่บ้าน ใช้ 에서
ข้อผิดพลาดที่พบบ่อย
  • ใช้ 에서 กับจุดหมาย — 집에서 가요 ✗ → 집에 가요 ✓
  • ใช้ 에 กับการกระทำ — 카페에 공부해요 ✗ → 카페에서 공부해요 ✓
  • ใช้ 에서 กับ 있어요 — 집에서 있어요 ✗ → 집에 있어요 ✓
  • วางคำช่วยไว้หน้าคำนามแบบคำบุพบทไทย — 에 집 ✗ → 집에 ✓
