คำบอกเวลาอยู่ต้นประโยค

어제 (เมื่อวาน) 아까 (เมื่อกี้) และ 지난주 (สัปดาห์ที่แล้ว) วางไว้ต้นประโยคเพื่อบอกฉาก แต่คำบอกเวลาอย่างเดียวไม่พอ ประโยคอย่าง เมื่อวานไปตลาด กริยาต้องเป็นรูปอดีตเสมอ ส่วน ไม่ได้ + กริยา ในภาษาไทยตรงกับ 안 + รูปอดีต: ไม่ได้ไป = 안 갔어요 (อย่าสับสนกับ ไปไม่ได้ ซึ่งแปลว่าทำไม่ได้)

{{ex:ko.s0095}}{{ex:ko.s0096}}{{ex:ko.s0097}}

ข้อผิดพลาดที่พบบ่อย
  • 가었어요 ✗ → 갔어요 ✓ (เริ่มจาก 가요 ไม่ใช่ 가다)
  • 하었어요 ✗ → 했어요 ✓
  • 학생였어요 ✗ → 학생이었어요 ✓ (มีตัวสะกด → 이었어요)
  • 갔어요 안 ✗ → 안 갔어요 ✓
