ภาษาไทยมีสามคำ: เป็น / คือ บอกว่าสิ่งหนึ่งคืออะไร มี บอกว่ามีอยู่หรือเป็นเจ้าของ และ อยู่ บอกตำแหน่ง ภาษาเกาหลีใช้แค่สองแบบ 이에요/예요 = เป็น / คือ ส่วน 있어요 = มี และ อยู่ รวมไว้ในคำเดียว คำตรงข้ามคือ 없어요 = ไม่มี และ ไม่อยู่ แค่สองคำสั้น ๆ ก็ขอสิ่งที่ต้องการได้ครึ่งหนึ่งแล้ว

มี ไม่มี

있어요 = มี / มีไหม 없어요 = ไม่มี ถามโดยขึ้นเสียงท้ายประโยค ไม่ต้องมีคำว่า ไหม แล้วตอบด้วยกริยาเดิม เหมือนที่คนไทยตอบว่า มี หรือ ไม่มี

คำช่วยบอกประธาน 이/가

สิ่งที่มีอยู่ใช้ 이 หลังตัวสะกด และ 가 หลังสระ ภาษาไทยไม่มีคำแบบนี้ จึงต้องฝึกให้ชิน

{{ex:ko.s0049}}{{ex:ko.s0050}}{{ex:ko.s0051}}

การเป็นเจ้าของ

ภาษาไทยพูดว่า ฉันมีแมว ภาษาเกาหลีพูดว่า “ส่วนฉัน แมวมีอยู่” เจ้าของใช้คำช่วยบอกหัวเรื่อง 은/는 ส่วนสิ่งที่มีใช้ 이/가

{{ex:ko.s0052}}{{ex:ko.s0053}}{{ex:ko.s0054}}

บอกว่าอยู่ที่ไหน: สถานที่ + 에

ภาษาไทยวาง ที่ ไว้หน้าสถานที่ (อยู่ที่บ้าน) ภาษาเกาหลีวาง 에 ไว้หลังสถานที่ แล้วตามด้วย 있어요 หรือ 없어요

{{ex:ko.s0055}}{{ex:ko.s0056}}{{ex:ko.s0057}}{{ex:ko.s0058}}

이에요 หรือ 있어요

ลองถามตัวเองว่า ในภาษาไทยจะพูดว่า มี อยู่ หรือ ไม่มี หรือเปล่า ถ้าใช่ ใช้ 있어요 หรือ 없어요 ถ้าประโยคเป็นแบบ “A = B” (เป็น / คือ) ใช้ 이에요/예요

ภาษาไทยภาษาเกาหลีเหตุผล
เป็นนักเรียน학생이에요เป็น: ฉัน = นักเรียน
อยู่ที่โรงเรียน학교에 있어요อยู่: บอกตำแหน่ง
ที่นี่คือโรงเรียน여기는 학교예요คือ: ที่นี่ = โรงเรียน
ที่นี่มีโรงเรียน여기에 학교가 있어요มี: บอกว่ามีอยู่
ในภาษาพูด 이/가 มักหายไปในคำถามสั้น ๆ เช่น 시간 있어요? (ว่างไหมครับ/คะ) คือประโยคที่คนพูดกันจริง แต่ยังต้องใช้ 이/가 เวลาอ่านและเวลาสร้างประโยคที่ยาวขึ้น
ข้อผิดพลาดที่พบบ่อย
  • บอกตำแหน่ง — รูปเต็มคือ 저는 학교에 있어요 ✓ (ในภาษาพูดแบบสบาย ๆ ก็ได้ยิน 지금 학교예요 “ตอนนี้อยู่ที่โรงเรียนครับ/ค่ะ” ด้วย)
  • ใช้ 이에요 แทน มี — 저는 고양이예요 ✗ (= “ฉันเป็นแมวครับ/ค่ะ”) → 저는 고양이가 있어요 ✓
  • 이/가 ผิด — 시간가 있어요 ✗ → 시간이 있어요 ✓
  • ลืม 에 — 고양이가 집 있어요 ✗ → 고양이가 집에 있어요 ✓ (ภาษาไทยพูดว่า แมวอยู่บ้าน ได้โดยไม่มี ที่ แต่ภาษาเกาหลีต้องมี 에)
