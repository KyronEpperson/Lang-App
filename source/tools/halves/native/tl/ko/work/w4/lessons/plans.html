Tatlong ending ang sapat para sa lahat ng imbitasyon. Idikit ang mga ito sa verb stem.

EndingDatingHalimbawa
-(으)ㄹ까요?"…kaya tayo?": malambot na mungkahi, parang Ano kaya kung…?커피 마실까요? / 카페 갈까?
-(으)ㄹ래요?"Gusto mo bang…?": tinatanong ang gusto niya같이 갈래요? / 영화 볼래?
-자"…tayo!": casual at desidido na, parang Tara! o Kain tayo!놀자! / 밥 먹자

ㄹ pagkatapos ng vowel stem (가 → 갈까요), 을 pagkatapos ng consonant stem (먹 → 먹을까요).

Pagpayag at pagtanggi

{{ex:ko.s0202}}{{ex:ko.s0203}}{{ex:ko.s0204}}
Kinukumpirma ng mga Koreano ang tagpuan gamit ang lugar + numero ng exit, hindi address: 강남역 11번 출구. Alamin ang mga exit ng istasyon mo.
Karaniwang mga mali
  • 볼래요 sa mas matanda: gamitin ang 보실래요 o 볼까요?
  • Pagbibigay ng address: istasyon + exit ang sinasabi ng mga Koreano: 강남역 11번 출구.
  • Pagpayag na 네 lang: dagdagan ng 좋아요 o 콜 (parang Game!) para masigla ang dating.
