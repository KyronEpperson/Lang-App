Nagbibilang ang Koreano gamit ang native number + counter. Depende sa binibilang ang counter, gaya ng dalawang tasa ng kape o tatlong piraso ng papel sa Tagalog, pero dito, laging kailangan. At baligtad ang ayos: sa Tagalog, number muna (dalawang kape); sa Koreano, noun muna, tapos number, tapos counter. Ang Ilan? o Ilang piraso? mo ay tanong din na may counter sa Koreano.

Ang pagbabago ng 1–4

Bago ang counter: 하나 → 한, 둘 → 두, 셋 → 세, 넷 → 네, 스물 → 스무. Walang pagbabago ang iba. Native number din ang edad: kahit bente singko anyos ang sinasabi mo, 스물다섯 살 ito sa Koreano.

Word order

Noun + number + counter: 맥주 (noun) 두 (number) 병 (counter). Ang particle, kung mayroon, ay nasa likod ng counter: 맥주 두 병을 마셨어요.

Nalilito? Gumagana ang 개 para sa halos lahat ng bagay at walang magtataka. Huwag lang kailanman gamitin ang 개 sa tao (명). Para sa inumin, 잔 ang counter ng textbook, pero karaniwan din ang 개 kapag umo-order sa cafe.
Karaniwang mga mali
  • 두 명 para sa inumin ✗: pang-tao ang 명; 잔 ang inumin.
  • 세 개 사람 ✗: noun + number + counter ang ayos: 사람 세 명.
  • 스물 살 ✗: nagiging 스무 ang 스물 bago ang counter: 스무 살.
