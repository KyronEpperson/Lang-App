## Where w2 dialogue lines differ from NOTES-w1 (reviewer)

- 斤 is taught as a false friend: Vietnamese «cân» colloquially = 1 kg; 斤 = 500 g, so 苹果多少钱一斤 → «Táo bao nhiêu tiền một cân (500 g)?»
- Pinyin anchors (lesson pinyin; w1's Pinyin sounds cards and w3 should match): b/d/g = «p (pin) / t / c» unaspirated; p/t/k = aspirated like «th», p ≠ «ph», k ≠ «kh»; h ≈ «kh»; q ≈ «ch» (cha) + puff, never «qu»; j ≈ «ch» no puff; x ≈ softer «x», tongue flat behind lower teeth; zh/ch/sh/r = tongue curled: Southern «tr» / «tr» + puff / Southern «s» / Southern «r»; z/c = «ts» (c with puff), not «ch»; e ≈ «ơ»; ü = «i» with rounded lips, not «uy»; -i after z c s zh ch sh r ≈ «ư»; ian ≈ «iên»; ui ≈ «uây»; iu ≈ «iâu»; ing = «i» + back «ng», not «inh».
- accent bar → «hàng phím dấu thanh» (as NOTES-w3); tip label «Lỗi thường gặp:».
- Hán Việt not confirmed on an opened page → skip: 错 (thác/thố), 不错, 眼睛 (睛), 有空 (空 kòng), 比较 (較 giác/giảo), 你, 他, 她, 它, 您.
- 安 read «yên» in 安静 (yên tĩnh, Wiktionary lists yên as a Hán Việt reading) and «an» in 安全. 层 hv «tằng» (Wiktionary: tầng is the non-Sino-Vietnamese reading).
