## Other sentences and decisions w4 set
- 我明天去北京 → Ngày mai tôi đi Bắc Kinh. · 明天我去北京 → Ngày mai, tôi đi Bắc Kinh.
- 我想喝咖啡 → Tôi muốn uống cà phê.
- 我要一碗面条 → Tôi lấy một bát mì. · 我要… when ordering = «Tôi lấy…»; 来… = «Cho…»; 请给我… = «Làm ơn cho tôi…»
- 你几岁 → Cháu mấy tuổi? (hỏi trẻ em) · 你多大 → Bạn bao nhiêu tuổi? (hỏi người lớn)
- 王明 → Vương Minh (profile §3.1)
- 了 glosses: «… rồi» (我买了两张票 → Tôi mua hai vé rồi.; 我昨天去上海了 → Hôm qua tôi đi Thượng Hải rồi.; 天气冷了 → Trời lạnh rồi.); never đã alone
- 没 past: «không» + time word, never «đã không» (我昨天没去 → Hôm qua tôi không đi.) · 还没 → chưa
- 在/正在 + verb → đang; 正在…呢 → «đang … đây»
- 吧: 我们…吧 → «Chúng ta … đi / thôi / nhé»; 别 → Đừng; 不要 + verb → Không được / Đừng
- 还是 → hay (question) · 或者 → hoặc (statement)
- measure words: 杯 cốc · 碗 bát · 瓶 chai · 本 quyển · 张 tờ/tấm (vé: «vé» alone) · 只 con · 件 chiếc · 双 đôi
- 地铁 tàu điện ngầm · 高铁 tàu cao tốc · 兵马俑 tượng binh mã · 长城 Vạn Lý Trường Thành · 成都 Thành Đô · 西安 Tây An
- prompt cues: «(bắt đầu bằng 我)», «(hỏi bạn bè)», «(nói với khách)», «(dùng 想)»; mc stems «“…” =»; «Pinyin của X (…) là gì?»
- tip label in bodies: «Lỗi thường gặp:» (as vi-ko)
- 能愿动词 → động từ năng nguyện · 连动句 → câu liên động · 离合词 → động từ ly hợp · A-not-A → câu hỏi chính phản
