Hangul is an alphabet, not a character system. Every block is one syllable built from letters. Learn the letters and you can read anything out loud, even without knowing what it means.

Vowels are sticks

A vertical stick is ㅣ (i). A horizontal stick is ㅡ (eu). Add a tick to make the others:

VerticalSoundHorizontalSound
ㅏaㅗo
ㅓeo (uh)ㅜu (oo)
ㅣi (ee)ㅡeu
ㅐ / ㅔe (bed)

Two ticks = add a y: ㅑ ya, ㅕ yeo, ㅛ yo, ㅠ yu.

Consonants are mouth shapes

The basic five were drawn from the tongue and lips: ㄱ (g, tongue back), ㄴ (n, tongue tip up), ㅁ (m, lips), ㅅ (s, teeth), ㅇ (silent placeholder, throat). Adding a stroke makes a harder sound: ㄴ→ㄷ (d)→ㅌ (t); ㅁ→ㅂ (b)→ㅍ (p); ㅅ→ㅈ (j)→ㅊ (ch); ㄱ→ㅋ (k); ㅇ→ㅎ (h).

Stacking

Consonant first, then vowel. Vertical vowels go to the right; horizontal vowels go below. A final consonant (받침, batchim) goes at the bottom.

ㅇ at the start of a block is silent; it only holds the vowel's place. At the end it sounds like ng: 강 = gang.
