Korean offices run on titles and set phrases. Learn the set phrases and you sound like you belong on day one.

Titles (always + 님)

TitleRoughly
사원staff (not used to address anyone: say name + 씨)
대리님assistant manager
과장님manager
차장님 / 부장님senior manager / department head
팀장님team lead
사장님 / 대표님CEO

Address people by title, not name: 과장님, 이거 확인해 주시겠어요? If unsure of someone's title, ask a colleague; in chat, name + 님 is safe.

회식 rules

Pour for others with two hands, receive with two hands, turn slightly away from seniors when you drink, and never pour your own. 한 잔만 할게요 (just one glass) is accepted; 운전해야 돼요 (I have to drive) ends the pressure.
