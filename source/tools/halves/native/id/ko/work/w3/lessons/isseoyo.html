Bahasa Indonesia sudah memisahkan apa yang dipisahkan bahasa Korea, jadi pelajaran ini terasa akrab. 이에요/예요 mengatakan sesuatu itu apa (Saya mahasiswa). 있어요 adalah ada: sesuatu ada, berada di suatu tempat, atau kamu punya. Lawannya 없어요, yaitu tidak ada. Satu perbedaan: untuk "punya", bahasa Korea juga memakai 있어요, seperti bahasa lisan Saya ada mobil. Dua kata kerja pendek, dan kamu sudah bisa meminta separuh kebutuhanmu.

Ada, tidak ada

있어요 = ada / ada?; 없어요 = tidak ada. Bertanya dengan nada naik, menjawab dengan kata kerja yang sama, persis seperti Ada? — Ada.

Penanda subjek 이/가

Benda yang ada mendapat 이 setelah konsonan dan 가 setelah vokal.

Punya sesuatu

Bahasa Korea bilang "kalau saya, X ada". Penanda topik 은/는 untuk pemiliknya, 이/가 untuk bendanya.

Letak benda: tempat + 에

Taruh 에 di belakang tempatnya (bahasa Indonesia menaruh di di depan), lalu 있어요 atau 없어요.

이에요 atau 있어요?

Kalau kalimatnya "A = B" (dalam bahasa Indonesia tanpa ada), pakai 이에요/예요. Kalau kalimatnya tentang berada di suatu tempat, keberadaan, atau punya sesuatu (dalam bahasa Indonesia dengan ada atau punya), pakai 있어요. Negatifnya juga sejalan: bukan untuk A = B, tidak ada untuk 있어요.

Dalam percakapan, 이/가 sering hilang dalam pertanyaan pendek: 시간 있어요? (ada waktu?) adalah cara orang benar-benar bertanya. Kamu tetap perlu 이/가 untuk membaca dan untuk menyusun kalimat yang lebih panjang.
Kesalahan umum
  • 있어요 untuk letak — bentuk lengkapnya 저는 학교에 있어요 ✓ (dalam percakapan sehari-hari kamu juga akan mendengar 지금 학교예요, "sekarang saya di sekolah")
  • 이에요 untuk punya — 저는 고양이예요 ✗ (= saya kucing) → 저는 고양이가 있어요 ✓
  • 이/가 salah — 시간가 있어요 ✗ → 시간이 있어요 ✓
  • Lupa 에 — 고양이가 집 있어요 ✗ → 고양이가 집에 있어요 ✓
