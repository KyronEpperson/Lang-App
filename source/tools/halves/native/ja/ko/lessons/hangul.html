ハングルは表意文字ではなく、アルファベットの一種です。かなは1文字で1つの音を表しますが、ハングルは子音と母音の字を組み合わせて、ひとまとまりの文字（1音節）を作ります。字を覚えれば、意味がわからなくても何でも声に出して読めます。言語の名前は「韓国語」、文字の名前が「ハングル」です（大学などでは「朝鮮語」という名前も使われます）。

母音は棒でできている

縦の棒が ㅣ（i）、横の棒が ㅡ（eu）です。短い線を足すと、ほかの母音になります：

縦音横音
ㅏa：日本語の「ア」ㅗo：唇を小さく丸めて突き出す「オ」
ㅓeo：口を「ア」のように大きく開け、唇を丸めずに言う「オ」ㅜu：唇を丸く突き出す「ウ」
ㅣi：日本語の「イ」ㅡeu：唇を横に引いたまま言う「ウ」
ㅐ / ㅔe：日本語の「エ」（今はどちらも同じ音）

ㅓ と ㅗ はカタカナではどちらも「オ」、ㅜ と ㅡ はどちらも「ウ」になってしまいます。日本語の「ウ」は ㅜ と ㅡ のちょうど中間なので、どちらかにはっきり寄せましょう。eo と eu は、ローマ字では2文字でも1つの母音です。

線を2本にすると y がつきます：ㅑ ya、ㅕ yeo、ㅛ yo、ㅠ yu。

子音は口の形

基本の5つは、舌と唇の形から作られました：ㄱ（g、舌の奥）、ㄴ（n、舌先を上に）、ㅁ（m、唇）、ㅅ（s、歯）、ㅇ（音のない席、のど）。線を足すと強い音になります：ㄴ→ㄷ（d）→ㅌ（t）、ㅁ→ㅂ（b）→ㅍ（p）、ㅅ→ㅈ（j）→ㅊ（ch）、ㄱ→ㅋ（k）、ㅇ→ㅎ（h）。

ㄱg/kㅋk
ㄴnㄷd/tㅌt

g/k のように音が2つあるものは、1つ目が音節の最初、2つ目が音節の最後に来たときの音です。

組み立て方

子音が先、母音があと。縦の母音は右に、横の母音は下に置きます。最後の子音（받침、パッチム）はいちばん下に入ります。ひとまとまりの文字が1音節で、日本語の拍とは数え方が違います。

ローマ字の読み方。韓国語の下のローマ字は、発音どおりに書いた公式の「改訂ローマ字表記」です（감사합니다 → gamsahamnida）。基本はローマ字読みで大丈夫ですが、カタカナでは区別できない音があるので、このコースではカタカナの読み方は使いません。次の点に気をつけましょう。

母音。a・i・e は日本語の「ア」「イ」「エ」とほぼ同じで、ae（ㅐ）も「エ」です。eo（ㅓ）と eu（ㅡ）は「エオ」「エウ」とは読みません。yeo と yo の違いは、eo と o の違いと同じです。wa, wo, wi（ㅘ ㅝ ㅟ）は「ワ」「ウォ」「ウィ」：w をはっきり言いましょう（gwa を「ガ」、wi を「イ」にしないように）。oe, wae, we（ㅚ ㅙ ㅞ）はどれも「ウェ」で、「オエ」「ワエ」とは読みません：joesonghamnida、dwaeyo。ui（ㅢ）は ㅡ から ㅣ へすばやく移る音です。ただし joeun（jo・eun と2つに分ける）のように、ローマ字だけでは区切りがわからないこともあります。迷ったらハングルを見ましょう。

子音：平音・激音・濃音。g, d, b, j（ㄱ ㄷ ㅂ ㅈ、平音）は語頭では濁りません。「カ・タ・パ・チャ」に近い、息の弱い音です。母音にはさまれると「ガ・ダ・バ・ジャ」のように濁ります。gamsahamnida の g は「カ」に近い音です。k, t, p, ch（ㅋ ㅌ ㅍ ㅊ、激音）は強い息と一緒に出します。口の前に手をかざして、息が当たるのを確かめましょう。日本語話者は激音を濃音で言ってしまいがちなので、ためらわずに息を出しましょう。kk, tt, pp, ss, jj（ㄲ ㄸ ㅃ ㅆ ㅉ、濃音）は長い音ではありません。前に小さい「っ」があるつもりで、のどを締め、息を出さずに言います。oppa（오빠）は「オッパ」に近い音です。

h（ㅎ）は「ハ」行の音ですが、母音にはさまれるとほとんど聞こえません（joayo）。r / l（ㄹ）は、母音にはさまれると「ラ」行と同じ r、文字の最後では l になります。l は舌先を上の歯ぐきにつけたまま止め、「ル」のように母音をつけません。mul（물）は「ムル」ではありません。s は i の前で「シ」になります。

パッチム。パッチムには母音をつけません。bap（밥）は「バプ」ではなく、唇を閉じて止めます。k, t, p で終わる音は、小さい「っ」で止める感じです（hakgyo ≈「ハッキョ」）。n, m, ng は日本語ではどれも「ん」ですが、韓国語でははっきり区別します。日本語の「ん」の言い分けで覚えましょう：n（ㄴ）は「あんない（案内）」の「ん」（舌先を上の歯ぐきにつける）、m（ㅁ）は「さんま」の「ん」（唇を閉じる）、ng（ㅇ）は「りんご」の「ん」（舌の奥を上げ、口は開けたまま）。特に ng を n で言ってしまわないように注意しましょう。

リズム。1文字を1拍のつもりで言います。hanguk（한국）は「ハ・ン・グ・ク」の4拍ではなく、2拍です。長い音はないので、seoul（서울）を「ソウール」と伸ばさないように。単語ごとの高低アクセントもありません。平らに言い、質問の文末だけ上げます。

文字の最初の ㅇ は発音しません。母音の席を埋めるだけです。最後に来ると ng（「りんご」の「ん」）になります：강 ＝ gang（「カン」の「ん」ではなく、口を開けたままの ng）。
文字は全部でいくつ？ 全部で40個です。このレッスンで学ぶのは基本の24個（子音14個と母音10個）です。残りの16個は基本の文字を組み合わせて作ります：濃音の子音5個（ㄲ kk, ㄸ tt, ㅃ pp, ㅆ ss, ㅉ jj）と合成母音11個（ㅐ ae, ㅔ e, ㅒ yae, ㅖ ye, ㅘ wa, ㅙ wae, ㅚ oe, ㅝ wo, ㅞ we, ㅟ wi, ㅢ ui）。ㅐ と ㅔ は「ハングル・母音」のデッキに、そのほかは「ハングル・発展」にあります。
