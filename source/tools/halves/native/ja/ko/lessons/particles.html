에 は「に」、에서 は「で」と、ほぼそのまま対応します。에 は行く・来る・いる（ある）場所と時に、에서 は何かをする場所に使います。日本語と違うのは2点だけです。에서 は場所の「から」も表すこと、そして12課で見たように、「〜に乗る」「〜に会う」など「に」でも 에 を使わない動詞があることです。

에：行き先

行き先 + 에 に 가요（行きます）、와요（来ます）を続けます。「学校に行きます」と同じ形です。

{{ex:ko.s0120}}{{ex:ko.s0121}}{{ex:ko.s0122}}

에：ある場所と時

ある・いる場所 + 에 に 있어요 / 없어요。時を表す言葉にも 에 をつけます：주말에（週末に）、아침에（朝に）。

{{ex:ko.s0056}}{{ex:ko.s0123}}{{ex:ko.s0124}}

에서：何かをする場所、そして「から」

食べる、勉強する、休む、働くなど、動作をする場所には 에서（「で」）。また 왔어요 と使うと「〜から来ました」の「から」になります。日本語は「で」と「から」を分けますが、場所については 에서 ひとつです。

{{ex:ko.s0125}}{{ex:ko.s0126}}{{ex:ko.s0299}}

主題と主語をひとことで

은/는 は「は」、이/가 は「が」とほぼ同じ使い分けです。「誰が来ましたか」「友達が来ました」のように、新しい情報や「誰？」への答えには 이/가 を使います。

{{ex:ko.s0128}}{{ex:ko.s0129}}

これまでの助詞のまとめ

働きパッチムありパッチムなし例
主題「は」은는저는（私は）
主語「が」이가고양이가（猫が）
目的語「を」을를밥을（ご飯を）
行き先・ある場所・時「に」에집에 가요 · 주말에
動作の場所「で」・「から」에서집에서 쉬어요
「も」도저도（私も）— 次の課で
見分け方：動詞を見ましょう。가요、와요、있어요、없어요 → 에。そこで何かをする（먹어요、공부해요、쉬어요）→ 에서。日本語で「に」か「で」かを考えても、ほぼ同じ答えになります。
よくある間違い
  • 行き先に 에서 — 집에서 가요 ✕ → 집에 가요 ○（집에서 가요 は「家から行きます」）
  • 動作の場所に 에 — 카페에 공부해요 ✕ → 카페에서 공부해요 ○
  • 있어요 に 에서 — 집에서 있어요 ✕ → 집에 있어요 ○（「家でいます」と言わないのと同じ）
  • 助詞を名詞の前に置く — 에 집 ✕ → 집에 ○
