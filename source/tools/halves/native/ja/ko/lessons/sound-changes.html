韓国語は、つづりで意味を表し、話すときに音をなめらかにします。だから 감사합니다 は「gamsahamnida」と発音し、hap-ni-da とは言いません。4つの習慣で、ほとんどの「あれ？」が説明できます。このコースのローマ字は話すときの音で書いてあるので、ローマ字のとおりに読めば、ほとんどの変化は自然にできます（濃音化だけはローマ字に表れません）。つづり（ハングル）は変わらないので、書くときは元のつづりで書きましょう。日本語でも、「さんぽ」の「ん」は唇を閉じ、「さんか」の「ん」はのどの奥で言うように、音は次の音に合わせて変わります。

1 · 連音化：パッチムが次の文字に移る

次の文字が音のない ㅇ で始まると、パッチムがその空いた席に移ります。hangugeo のように、区切らずに続けて読みましょう。

2 · 鼻音化：ㄴ・ㅁ の前の ㅂ ㄷ ㄱ

ㄴ や ㅁ の前では、ㅂ は ㅁ、ㄷ は ㄴ、ㄱ は ㅇ（ng）になります。

3 · 激音化と ㅎの弱化

ㅎ が ㄱ ㄷ ㅂ ㅈ と隣り合うと、息の強い ㅋ ㅌ ㅍ ㅊ になります。母音にはさまれた ㅎ は、ほとんど聞こえなくなります。

4 · 流音化：ㄴ と ㄹ は両方 ㄹ に

ㄴ と ㄹ が隣り合うと、どちらも ㄹ になり、長い l で発音します。

{{ex:ko.s0028}}{{ex:ko.s0029}}
もう一つよく聞く変化が濃音化です。ㄱ ㄷ ㅂ のあとの平音は濃音になるので、학교 は 학꾜 のように聞こえます。日本語の「学校（がっこう）」の「っこ」と同じ感覚です。この変化だけはローマ字に表れません（hakgyo）。耳と口を慣らすには、「レッスン」の例文をローマ字と見比べながら声に出し、「練習」と「復習」でくり返しましょう。
よくある間違い
  • 1文字ずつ区切って読む — gam-sa-hap-ni-da ✕ → gamsahamnida ○
  • ㅇ の前で間を空ける — han-guk-eo ✕ → hangugeo ○
  • 좋아요 の ㅎ を発音する — jo-ha-yo ✕ → joayo ○
  • 聞こえたとおりに書く — 조아요 ✕ → 좋아요 ○（つづりは変わりません）
