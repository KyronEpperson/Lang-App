毎日使う2つの形です。「〜たい」は動詞につけ、「好き」は名詞を目的語にとります。

〜たい：語幹 + 고 싶어요

다 を取って 고 싶어요 をつけるだけです。「〜たいです」とそっくり同じ使い方で、母音の規則も考えなくてかまいません。

{{ex:ko.s0165}}{{ex:ko.s0166}}{{ex:ko.s0167}}

何を・どこに を前に足す

文のほかの部分はそのままで、動詞の語尾だけが変わります。ただし、日本語で「水が飲みたい」と「が」を使うときも、韓国語では 을/를 です。

{{ex:ko.s0168}}{{ex:ko.s0169}}{{ex:ko.s0170}}

〜たくない、〜たかった

前に 안 を置くか、싶어요 を過去形にします。

{{ex:ko.s0171}}{{ex:ko.s0172}}

好き：名詞 + 을/를 좋아해요

ここが日本語話者のいちばんの落とし穴です。日本語は「コーヒーが好き」ですが、좋아해요 は「好む」という動詞なので、好きなものには 을/를 をつけます。よく似た 좋아요（いいです）は形容詞なので 이/가 をとり、「〜がいいです」にあたります。

{{ex:ko.s0173}}{{ex:ko.s0174}}{{ex:ko.s0175}}{{ex:ko.s0176}}
ものが欲しいとき、韓国語ではふつう動作で言います。「コーヒーが欲しいです」は 커피 마시고 싶어요（コーヒーが飲みたいです）、またはただ 커피 주세요（コーヒーください）です。
よくある間違い
  • 가다고 싶어요 ✕ → 가고 싶어요 ○（先に 다 を取る）
  • 가요 싶어요 ✕ → 가고 싶어요 ○
  • 커피가 좋아해요 ✕ → 커피를 좋아해요 ○（「が好き」につられない）
  • 커피를 좋아요 ✕ → 커피가 좋아요 ○
