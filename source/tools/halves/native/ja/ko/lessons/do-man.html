도 は「も」、만 は「だけ」です。使い方も日本語とまったく同じで、「は・が・を」の代わりに入り、「に・で」には重ねます（「にも」「でも」）。つまり 은/는・이/가・을/를 は 도 / 만 に置き換わり、에・에서 のあとには 도 / 만 が続きます。

도＝「も」

「〜も」と言いたいものに 도 をつけます。

{{ex:ko.s0143}}{{ex:ko.s0144}}{{ex:ko.s0145}}

도 は 은/는・이/가・을/를 の代わりに

「私は → 私も」「友達が → 友達も」と同じで、元の助詞は消えます。重ねません。

{{ex:ko.s0146}}{{ex:ko.s0147}}{{ex:ko.s0148}}

만＝「だけ」

만 も 은/는・이/가・을/를 の代わりに入ります。이것 は 이거（これ）の元の形です。

{{ex:ko.s0149}}{{ex:ko.s0150}}{{ex:ko.s0151}}{{ex:ko.s0152}}

에・에서 には重ねる

「家にも」「学校でも」「週末にだけ」と同じです。에・에서 は残り、そのあとに 도 / 만 がつきます。

{{ex:ko.s0153}}{{ex:ko.s0154}}{{ex:ko.s0155}}
도 + 否定で「〜も〜ない」：저도 안 가요＝私も行きません。저도요（私もです）は、どんな会話にも加われるいちばん簡単なひとことです。
よくある間違い
  • 은/는 に 도 を重ねる — 저는도 ✕ → 저도 ○（「私はも」と言わないのと同じ）
  • 을/를 に 만 を重ねる — 커피를만 마셔요 ✕ → 커피만 마셔요 ○
  • 에 を落とす — 집도 있어요（＝家もあります）✕ → 집에도 있어요 ○
  • 順番の間違い — 학교도에서 ✕ → 학교에서도 ○（「学校もで」ではなく「学校でも」）
