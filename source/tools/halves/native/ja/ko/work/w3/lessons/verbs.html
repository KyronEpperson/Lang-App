辞書形は 다 で終わります：가다（行く）、먹다（食べる）、하다（する）。다 を取って語幹にし、丁寧な語尾をつけます。この形ひとつで、日本語の「行きます」「行くところです」「行きますか」をすべて表せます。

語尾は最後の母音で決まる

語幹の最後の母音を見ます。陽母音（ㅏ・ㅗ）なら 아요、それ以外の陰母音なら 어요 です。日本語にはない仕組みですが、規則はこれだけです。

最後の母音つける語尾例
ㅏ か ㅗ아요가다 → 가요 · 보다 → 봐요
それ以外어요먹다 → 먹어요 · 마시다 → 마셔요
하다 用言해요하다 → 해요 · 공부하다 → 공부해요

母音がくっつく

語幹が母音で終わると、2つの母音が溶け合います：가 + 아요 = 가요、오 + 아요 = 와요、마시 + 어요 = 마셔요。

パッチムのある語幹はそのまま

語幹がパッチムで終わるときは、何もくっつきません。

ひとつの形で何役も

平叙文も疑問文も「今〜している」も同じ形です。疑問文は語尾を上げるだけで、「か」にあたる語はありません。下の「今、何をしていますか」のように、動作が進行中の「〜ています」もこの形で言えます。ただし「結婚しています」「知っています」のような状態の「〜ています」は、韓国語では過去形や現在形で言います。「〜ています」をいつも同じ形に訳そうとしないようにしましょう。

{{ex:ko.s0083}}{{ex:ko.s0084}}{{ex:ko.s0085}}{{ex:ko.s0086}}
否定は、動詞のすぐ前に 안 を置きます：안 가요（行きません）。過去と未来は、このあとのレッスンで学びます。
よくある間違い
  • 가아요 ✕ → 가요 ○（母音がくっつく）
  • 먹아요 ✕ → 먹어요 ○（ㅓ には 어요）
  • 하어요 ✕ → 해요 ○（하다 は特別）
  • 辞書形で話す — 저는 가다 ✕ → 저는 가요 ○
