Dictionary forms end in 다: 가다 (go), 먹다 (eat), 하다 (do). Chop the 다 to get the stem, then add the polite ending. This one form covers "I go", "I'm going" and "do you go?".

Pick the ending by the last vowel

Look at the last vowel of the stem:

Last vowelAddExample
ㅏ or ㅗ아요가다 → 가요 · 보다 → 봐요
anything else어요먹다 → 먹어요 · 마시다 → 마셔요
하다 verbs해요하다 → 해요 · 공부하다 → 공부해요

Vowels merge

When the stem ends in a vowel, the two vowels melt together: 가 + 아요 = 가요, 오 + 아요 = 와요, 마시 + 어요 = 마셔요.

Consonant stems just add it

Nothing merges when the stem ends in a consonant.

One form, many jobs

Statement, question and "right now" all use the same word. A question only changes your tone.

For "not", put 안 right before the verb: 안 가요 (not going). Past and future each get their own lesson next.
Common mistakes
  • 가아요 ✗ → 가요 ✓ (the vowels merge)
  • 먹아요 ✗ → 먹어요 ✓ (ㅓ takes 어요)
  • 하어요 ✗ → 해요 ✓ (하다 is special)
  • Saying the dictionary form — 저는 가다 ✗ → 저는 가요 ✓
