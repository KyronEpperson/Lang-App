# te-en `pron` tool (rules: docs/profiles/te.md §6). **If the string is already in the course,** look up the exact English text (same punctuation and capitals) in `tools/content/te/pron_lookup.json` and paste the value verbatim. It covers 766 strings: every zh deck card, `{{ex}}` row and idiom. lint.js blocks one string with two different aids.
**For a new string,** first write the IPA in zh conventions (`tools/content/zh/PRON-RULES.md`: American values, ASCII g, ˈ on content words, weak forms, ` ‖ ` between sentences, numbers as words). Grep `tools/content/zh/` for the words and copy their IPA wherever they occur.
Then run `node tools/content/te/pron_te.js "/aɪ ˈlaɪk ˈmæŋgoʊz/"`, which prints ఐ లైక్ ˈమ్యాంగోజ఼్. Read the result aloud and compare it with the audio. Practice items carry no aid.
`node tools/content/te/pron_te.js --selftest` checks the 225 example pairs printed in §6 (the 58 worked rows, the key and rule examples), 21 bad inputs and the 13 respellings §6 says `pronPattern` rejects. Run it after any change to the converter. `--lookup` rebuilds `pron_lookup.json` from `tools/content/zh/`.
`node tools/content/te/pron_check.js [summary|all] [--strict]` checks the course files: SCAFFOLD (no Telugu yet), PATTERN, ENCODING (not NFC), BANNED (a character rule 14 bans), DIFF (a lookup string with another aid), CONFLICT, WORD (a new row that spells a word unlike every lookup row), PROSE (a quoted respelling that matches no row).
**The tool refuses:** any symbol outside the §6 table (ɡ U+0261, ɒ, ɹ, ɚ, ɾ; ɑ, ɔ, ɜ without ː; capitals, digits, punctuation); British əʊ, eə, ʊə, ɪə; text outside the slashes; an empty word or sentence; a dangling or doubled ˈ; any output that fails `pronPattern`.
**Copy, never retype.** The output is NFC and the dot is U+0C3C typed after the letter and before the pollu or vowel sign (థ + ఼ + ్ + ర + ీ). Paste ˈ as U+02C8. No ZWNJ anywhere. `pronPattern` accepts బస్సు and థింక్, so a hand-typed aid can be wrong and still pass validate.js.
**ˈ is on every word of two or more syllables and on no one-syllable word**; ˌ is dropped (rule 2 as amended 2026-11-23 by lead ruling: zh leaves some function words unmarked, e.g. *about* /əbaʊt/, *into* /ɪntə/; `pron_te.js` then takes the stress from a stressed zh occurrence of the same sounds, or from its `HAND_STRESS` table, and throws for a word neither covers). *twenty twenty-six* → ˈట్వెంటి ˈట్వెంటి సిక్స్.

**Hand case 2, weak or strong forms** come from the IPA you write. Use the strong form when the word is stranded, contrastive or alone (*Where are you from?* = frʌm, *you* = ˈjuː), then convert. *from* is ఫ్రమ్ both ways.
**Hand case 3, shapes no zh row has.** Check by eye and against the audio: consonant + ˈ + vowel (/wɪðˈɪn/ → విద఼్ˈఇన్); w or y before /æ/ (wax వ్యాక్స్, which also reads "vyaks"); /jɑː/ at a word start reads like /æ/ (yard = యార్డ్, §6 collapses: note it on the card).

## Decisions
No worked example contradicts a rule: all 58 rows and every example in the key and rules come out of the converter byte for byte. The points below are where §6 gives a rule but no example, or leaves a choice.
1. **Consonant + ˈ + vowel**: pollu, ˈ, independent vowel (విద఼్ˈఇన్). Rule 4 keeps the pollu before the mark and `pronPattern` wants a letter after ˈ. Same reading as hi and bn. No zh row has it.
2. **Syllabic l / n** as hi: l or n after a consonant other than r, with only consonants up to the word end (zh A4). So *suddenly* /ˈsʌdnli/ → ˈసడ్న్లి (a cluster), not సడన్. bn's wider reading gives the same result on every zh row.
3. **Sunna** looks through ˈ (ఇంˈపోర్టంట్, ఇంˈజాయ్) and treats a syllabic n as "after a vowel" (ˈడిడంట్). After a consonant the nasal is a letter (learnt లర్న్ట్). n before k / g is న్, not ం (ఇన్ˈక్లూడ్); only ŋ gives ంక / ంగ.
4. **ɔː is ో whenever the next sound is r**, ా otherwise (ˈస్టోరి, సా). ɔːr and oʊr would share ోర్; no zh word has oʊr.
5. **ɔɪ** = ా + య, then: pollu at the word end, the next vowel's sign before a vowel (ˈరాయల్), ి before a consonant. Before ˈ it also takes ి (employee ఇంప్లాయిˈఈ). ɔɪ + ɪ and ɔɪ + consonant share ాయి (§6's own *enjoying* / *point*).
6. **Syllable count for rule 2** is by vowel symbols, so aɪ + ə is two: tired ˈటైఅర్డ్, hour ˈఔఅర్ keep ˈ.
7. **ɑ, ɔ, ɜ without ː and British diphthongs are refused** (hi accepts ɑ and ɔ). zh PRON-RULES A1 and the zh checker treat them as errors.
8. **Two spellings stand for two IPA forms** in the lookup, both from the documented collapses: ఫ్రమ్ (frʌm / frəm) and హిజ఼్ (*he's* hiz / *his* hɪz). zh's two spellings of *McDonald's* (nəldz / nldz) also give one respelling.
