# kn-en `pron` tool (rules: docs/profiles/kn.md §6). **If the string is already in the course,** look up the exact English text (same punctuation and capitals) in `tools/content/kn/pron_lookup.json` and paste the value verbatim. It covers 766 strings: every zh deck card, `{{ex}}` row and idiom. lint.js blocks one string with two different aids.
**For a new string,** first write the IPA in zh conventions (`tools/content/zh/PRON-RULES.md`: American values, ASCII g, ˈ on content words, weak forms, ` ‖ ` between sentences, numbers as words). Grep `tools/content/zh/` for the words and copy their IPA wherever they occur.
Then run `node tools/content/kn/pron_kn.js "/aɪ ˈlaɪk ˈmæŋgoʊz/"`, which prints ಐ ಲೈಕ್ ˈಮ್ಯಾಂಗೋಜ಼್. Two slashed groups give alternatives (`"/ˌfɪfˈtiːn/ /ˈfɪfti/"` → ಫ಼ಿಫ಼್ˈಟೀನ್ / ˈಫ಼ಿಫ಼್ಟಿ). Read the result aloud and compare it with the audio. Practice items carry no aid.
`node tools/content/kn/pron_kn.js --selftest` checks the 237 example pairs printed in §6 (the 87 worked rows, which it also compares with the profile table byte for byte, and 150 key and rule examples), 30 bad inputs and 16 respellings `pronPattern` must reject. Run it after any change to the converter. `--lookup` rebuilds `pron_lookup.json` from `tools/content/zh/`.
`node tools/content/kn/pron_check.js [summary|all] [--strict]` checks the course files: SCAFFOLD (no Kannada yet), PATTERN, ENCODING (not NFC), BANNED (a character rule 13 bans, ಫ ಥ ದ without the dot, a dot on another letter), DOUBLED (ಬಸ್ಸು, ಹ್ಯಾಪ್ಪಿ: `pronPattern` cannot see these), DIFF (a lookup string with another aid), CONFLICT, WORD (a new row that spells a word unlike every lookup row), PROSE (a quoted respelling with ˈ that matches no row).
**The tool refuses:** any symbol outside the §6 table (ɡ U+0261, ɒ, ɹ, ɚ, ɛ, ɾ; ɑ, ɔ, ɜ without ː; a and o outside the diphthongs; capitals, digits, punctuation, Kannada letters); ɜː without r; British əʊ, ɪə, eə, ʊə; a consonant + /jɑː/ or /jɔː/ (decision 5); ŋ before k / g with no vowel before it; text outside the slashes; an empty word or sentence; a dangling or doubled ˈ; any output that fails `pronPattern`. It prints the reason and exits 1.
**Copy, never retype.** The output is NFC and the dot is U+0CBC typed after the letter and before the ್ or vowel sign (ಥ + ಼ + ್ + ರ + ೀ). Paste ˈ as U+02C8. No ZWNJ anywhere. `pronPattern` accepts ಬಸ್ಸು and a ವ that should be ವ಼, so a hand-typed aid can be wrong and still pass validate.js.
**How to read the output** (rules 4 and 5): every consonant with no vowel after it has ್, also the last one; a bare consonant is a schwa, also at the end of a word (*the* ದ಼, *banana* ಬˈನ್ಯಾನ). **ˈ appears only in words of two or more syllables** and ˌ is dropped (rule 2). Do not add marks: *twenty twenty-six* → ˈಟ್ವೆನ್ಟಿ ಟ್ವೆನ್ಟಿ ಸಿಕ್ಸ್.
**Hand case 1, names and places** (rule 11, §9): the lookup still has zh's 23 localised rows (Li Wei, China, Chinese, Beijing, Shanghai, Chengdu). Do not use them. Of the 735 scaffold rows, 682 are in the lookup and 53 are not (the Korea / Seoul / Busan / Minji / kimchi rows that will be localised, plus about 25 others such as *Good luck!*, *No, thanks.*, *I like movies.*). ## Decisions
No worked example contradicts a rule: all 87 rows and every example in the key and rules come out of the converter byte for byte. The points below are where §6 gives a rule but no example, or leaves a choice. Each takes the reading that keeps one IPA string = one respelling.
1. **Syllabic l / n** as hi and te: l or n after a consonant other than r, with only consonants up to the word end (zh A4). The consonant before it is bare (rule 6 wins over rule 4). So *suddenly* /ˈsʌdnli/ → ˈಸಡ್ನ್ಲಿ (a cluster), *girl* → ಗರ್ಲ್, *learnt* → ಲರ್ನ್ಟ್. By rule 6 itself /tn/ and /tən/ share one respelling (ˈಈಟನ್).
2. **ಂ** is written for ŋ before k / g only, and looks through ˈ (ಬ್ಯಾಂˈಕಾಕ್, as §6's own ಬೆಂಗˈಲುರೂ). It needs a vowel before it; otherwise the tool refuses. n before k / g is ನ್, never ಂ (ಇನ್ˈಕ್ಲೂಡ್); m before p / b is ಮ್.
3. **ɔː is ೋ whenever the next sound is r**, also when a vowel follows the r (ˈಸ್ಟೋರಿ); ಾ otherwise. ɔːr and oʊ + r share ೋರ್ (*showroom* ˈಶೋರೂಮ್). Not refused, because oʊ + r is a real sequence; no zh word has it.
4. **ɔɪ** = ಾ + ಯ: ಯ್ at the word end, before a consonant and before ˈ (ಪಾಯ್ನ್ಟ್, ಇಮ್ಪ್ಲಾಯ್ˈಈ); before a vowel the ಯ carries that vowel (ˈರಾಯಲ್, ಇನ್ˈಜಾಯಿಙ್). No vowel is inserted, so *point* and *enjoying* stay apart (te merges them).
5. **Consonant + /jɑː/ or /jɔː/ is refused**, because it would be read as consonant + æ (§6, known collapses: "write it in two words or move the example"). At the start of a word /jɑː/ is fine: yard ಯಾರ್ಡ್ cannot be confused with ಆ್ಯ.
6. **Syllable count for rule 2** is by vowel symbols, so aɪ + ə is two: tired ˈಟೈಅರ್ಡ್, hour ˈಔಅರ್ keep ˈ.
7. **ɑ, ɔ, ɜ without ː, ɜː without r and British diphthongs are refused**. zh PRON-RULES A1 and the zh checker treat them as errors.
8. **Two spellings stand for two IPA forms** in the lookup, both from the documented collapses: ಫ಼್ರಮ್ (frʌm / frəm) and ಹಿಜ಼್ (*he's* hiz / *his* hɪz). No two of the 766 IPA strings give the same respelling.
9. **Count.** §6 reports 776 distinct IPA strings in `packs/course-zh-en.js`; `tools/content/zh/` gives 814 rows, 766 distinct English strings and 766 distinct IPA strings (the same 766 keys as te's lookup). 0 refused, 0 conflicts.
