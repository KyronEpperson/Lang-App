# bn-en `pron` tool (rules: docs/profiles/bn.md §6). **If the string is already in the course,** look up the exact English text (same punctuation and capitals) in `tools/content/bn/pron_lookup.json` and paste the value verbatim. It covers 766 strings: every zh deck card, `{{ex}}` row and idiom. lint.js blocks one string with two different aids.
**For a new string,** first write the IPA in zh conventions (`tools/content/zh/PRON-RULES.md`: American values, ASCII g, ˈ on content words, weak forms, ` ‖ ` between sentences, numbers as words). Copy word IPA from zh rows wherever the same words occur.
Then run `node tools/content/bn/pron_bn.js "/aɪ ˈlaɪk ˈmæŋgoʊz/"`, which prints আই ˈলাইক ˈম্যাংগৌজ়. It refuses unknown symbols (ɡ, ɒ, ɔ or ɑ or ɜ without ː) and any output that fails `pronPattern`. Read the result aloud and compare it with the audio.
`node tools/content/bn/pron_bn.js --selftest` checks the 177 example pairs printed in §6 (the 35 worked rows, the key and rule examples, the minimal pairs). Run it after any change to the converter. `--lookup` rebuilds `pron_lookup.json` from `tools/content/zh/`.
`node tools/content/bn/pron_check.js [summary|all]` compares the course files with the lookup: DIFF (a lookup string with another aid), CONFLICT, WORD (a new row that spells a word unlike every lookup row), PROSE (a quoted respelling that matches no row) and ENCODING.
**Copy, never retype.** The output is NFC: য় is য + U+09BC (not U+09DF), dotted letters are base + U+09BC, র + ্যা carries a ZWJ (ˈর‍্যান) and hasanta + ব a ZWNJ (ˈহাজ়্‌বান্ড). These are invisible, so a retyped row fails lint.js or `pron_check.js` ENCODING. Paste ˈ as U+02C8 and ː as U+02D0.
**ˈ is copied from the IPA on every word, one-syllable words too** (rule 2, unlike hi), and ˌ is dropped. Every row needs at least one ˈ, so a weak form alone (/ðə/) is not a row.
**Hand case 1, names and places** (rule 10, §9): the lookup still has zh's 23 localised rows (Li Wei, China, Beijing, Shanghai, Chengdu). Do not use them. The bn strings need new IPA from the en-US TTS: listen first, then convert. Starting points to check against the voice: Rafi /ˈrɑːfi/ → ˈরাːফি, Nadia /ˈnɑːdiə/ → ˈনাːডিআ, Dhaka /ˈdɑːkə/ → ˈডাːকা (or /ˈdækə/ → ˈড্যাকা), Bangladesh /ˌbɑːŋgləˈdeʃ/ → বাːংগ্লাˈডেশ (or /ˌbæŋ…/ → ব্যাংগ্লাˈডেশ), Bangla /ˈbɑːŋglə/ → ˈবাːংগ্লা, taka /ˈtɑːkə/ → ˈটাːকা. Use one reading per name in the whole pack.
**Hand case 2, strings that are not in zh:** 53 English strings of the ko scaffold have no lookup row (the Korea / Seoul / Busan / kimchi rows that will be localised anyway, plus about 25 others such as *Good luck!*, *No, thanks.*, *I like movies.*). Write IPA from zh word forms and convert.
**Hand case 3, weak or strong forms** come from the IPA you write. Use the strong form when the word is stranded, contrastive or alone (*Where are you from?* = frʌm, *you* = ˈjuː), then convert. *from* is ফ্রাম both ways.
**Hand case 4, shapes no zh row has.** Check by eye and against the audio: consonant + ˈ + vowel (/wɪðˈɪn/ → ওয়িদ়্ˈইন); w or y before /æ/ (wax ˈওয়্যাক্স, yeah ˈইয়্যা); a word that ends in /ɔː/ after a consonant and has another vowel is refused (rule 4 cannot write it).

## Decisions
No worked example contradicts a rule: all 35 rows and every example in the key and rules come out of the converter byte for byte. The points below are where §6 gives a rule but no example, or leaves a choice.
1. **য় = য + U+09BC** (NFC), the form §2 recommends; rule 9 leaves the choice open. The tool refuses U+09DF in its output.
2. **ZWJ on every র + /æ/, also inside a cluster** (ˈট্র‍্যাভ়াল, ˈগ্র‍্যাব, ট্র‍্যান্স্ˈফার, কান্গ্র‍্যাচাˈলেইশান্জ়). Rule 9 says "র + /æ/" and shows only word-initial র. Standard spelling writes ট্র্যা without ZWJ, so this needs a font check (6 zh words).
3. **ZWNJ only where hasanta and ব are adjacent**, not when ˈ stands between them (`pronPattern` forbids it and no font joins across ˈ). Not after ম or ল, as rule 9 says.
4. **Syllabic l / n** uses rule 5's wording: after a consonant other than r and not before a vowel, anywhere in the word (suddenly → ˈসাডান্লি). hi requires only consonants up to the word end. No zh row differs between the two.
5. **/j/**: ি directly after a consonant, ই at the word start, after a vowel and after ˈ; then য় + sign, or independent উ / ঊ for /u ʊ uː/ (ˈকিঊট, ˈমিলিয়ান, ˈইঊঝ়ুআলি).
6. **/ŋ/**: ং before a consonant (also across ˈ: শ্যাংˈহাই) and at the word end, ঙ before a vowel.
7. **Consonant + ˈ + vowel**: hasanta, ˈ, independent vowel (rule 4 keeps the hasanta where ˈ splits a cluster; without it the consonant would read with অ).
8. **Word-final /ɔː/ after a consonant** is written bare only in a word with no other vowel (ˈস, ˈস্ট্র). Otherwise the tool refuses, because rule 4 reads a bare last consonant as vowelless.
9. **ɑ, ɔ, ɜ without ː are refused** (hi accepts them). zh PRON-RULES A1 and the zh checker treat them as errors.
10. **Two spellings stand for two IPA forms**, both from the documented collapses: ফ্রাম (frʌm / frəm) and হিজ় (*he's* hiz / *his* hɪz).
