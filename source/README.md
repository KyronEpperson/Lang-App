# Lang App source

`../index.html` is generated. Edit here, then build.

- `src/app.html` — engine + built-in English→Korean course
- `packs/course-ko-en.js` — English course for Korean speakers (generated by `tools/content/gen.js`)
- `packs/i18n-ko.js` — Korean interface dictionary (generated by `tools/i18n/gen.py`)
- `docs/MULTILANG-SPEC.md` — platform spec: contracts for course packs and UI dictionaries, acceptance checklist
- `build.sh` — src + packs → single-file app → site (+ CSP hash, verify_build)
- `harness.js` — Playwright regression harness (36 guards)

Adding a language = a new `packs/course-<native>-<target>.js` (and `packs/i18n-<native>.js` for a new interface language). See the spec §3.
The scripts assume the working layout `/home/claude/{src,packs,korean-site,…}`; adjust paths if you run them elsewhere.
